# 11 · 打工人系列「视频同款」主题（触发式换肤）

> **触发关键词**：用户消息里出现「**打工人的AI入门系列**」「**做给打工人的AI入门**」「**打工人系列**」「**4节课带你从Skill从入门到毕业**」「**Skill 系列**」，或用户明确说「**视频同款 / 课件视觉规范 / 用视频那套风格**」时，本页视觉一律走本主题。
> **没触发就走默认**：不命中关键词的页面，视觉仍按 `06-视觉风格与配图.md` 的科技蓝方块风，不要擅自换肤。

本主题来自《课件视觉规范 · 视频同款 v1.0》（原文全文在 `assets/themes/dagongren/视觉规范.md`，组件代码样例在 `assets/themes/dagongren/组件展示.html`，真实换肤成页 donor 在 `assets/themes/dagongren/示例/打工人01_换肤后.html`）。它**只换外观**：页面骨架、五块结构、文案规则、脚本、动画、三问卡、红线 1–17 **全部照旧**。与 `06` 冲突时（直角 / 无阴影 / 科技蓝 / 单色相 / 无渐变那几条），**以本主题为准**；`06` 里仍然有效的只有：圆角三档纪律的精神、配图不写字、SVG 用 `currentColor`、图片不外链。

## 1. 一句话风格

**暖白方格纸上的白色圆角卡片，墨黑粗体大字，一处橙色焦点；章节处整屏换成高饱和色块，金句处换成黑金暗场；配图是 3D 黏土质感的道具。**

关键词：纸白课件、粗黑体、橙色焦点、马克笔高光、色块翻页、黑金金句、黏土道具。

## 2. 三种底，全部都要出现

| 模式 | 用在哪 | 长什么样 |
|---|---|---|
| **A 纸白课件**（默认，约 75%） | 首屏、知识卡片、演示动画、小奈三问、正文 | 方格纸底 `#F2EEE5`（44px 方格线 `#E4DED2`）+ 白卡 + 墨黑字 + 橙色焦点 |
| **C 整屏色块** | 章节过渡（`.ch-band`）、知识总结（`.note` 自动变黄块） | 整条高饱和色块 + 白波点 + 超大 900 字 + 下划线 + 道具图 + 背景大数字。全页 2–3 条；颜色按 **橙 → 紫 → 青 → 黄 → 黑 → 蓝** 轮换，相邻不同色、同页不重色 |
| **B 黑金暗场** | 演示结论（`.anim-verdict` 自动变）、金句（`.gold`）、页脚（`.foot` 自动变） | 近黑 `#0B0B0C` + 暖金光晕 + 象牙白大字 + 金色短横。每页最多 2 处（页脚算 1 处） |

落点（skin.css 已做好，不用改结构）：首屏 / 知识卡 / 演示 / 三问卡 → A；每个大部分开头插一条 `.ch-band` → C；知识总结 → C 黄块；`.anim-verdict` / `.foot` → B。**色块和黑金是「翻页」感，里面不塞长段落**；正文回到 A。

## 3. 接入四步（Phase 3 落地时照做）

**第 1 步 · 贴 skin.css**：把 `assets/themes/dagongren/skin.css` **全文粘贴到** `page-template.html` 的 `<style>` **最后面**（skill 产物是单文件，不用 `<link>`）。它把原模板的设计令牌整体映射成视频同款（`--accent` 变橙 `#FF4D1A`、圆角 18px、描边 + 柔投影、暗色变黑金），**所有原组件自动换肤，不改类名、不改脚本**。

**第 2 步 · 字体内嵌（单文件必做）**：skin.css 里字体默认走相对路径 `assets/fonts/…`，单文件页面必须改成 base64 `data:` 字体，否则标题没有 900 那么粗、不像视频：

- **必嵌两个**：`NotoSansSC-900.woff`（标题/金句/卡题的视觉签名，约 1.7MB base64）+ `Inter-var.woff`（数字/编号，约 165KB）。在 skin.css 的 4 条 `@font-face` 里，**只保留 900 与 Inter 两条**，src 改为 `url("data:font/woff;base64,…")`；
- **500/700 不内嵌**：回退系统黑体（`PingFang SC` 等），正文观感足够；这样单文件只增重约 1.9MB 而不是 5.6MB。
- **目录模式例外**：用户明确要发一组页面、页面和资产放同一目录时，可保留相对路径 `assets/fonts/…`，并把 `fonts/`、`props/` 复制到页面同目录——此时必须向用户说明「字体没内嵌、发布时要带上 assets」。

**第 3 步 · 道具图内嵌**：配图只用 `assets/themes/dagongren/props/`（60 张 3D 黏土道具，透明 WebP）或按规范 §7 新生成的同风格道具；**页面用到哪几张就把哪几张转成 base64 `data:image/webp;base64,…` 直接写进 `<img src>`**（单张约 20–60KB），保持单文件零依赖。**不用 emoji、线性图标、扁平插画、真人照片、写实大脑当主图**；线框示意（`.fc-fig`）照旧内联 SVG，skin.css 会自动加粗到 3.2px、形状填白。

**第 4 步 · 每页加三样东西**（donor 页里都有，可直接抄）：

1. **首屏最上方角标 `.hud`**：`第 <b>01</b>/ 14 集<i class="hud-sep"></i>做给打工人的AI入门系列`（集数、总集数、系列名按当次内容写；Skill 系列写 `第 <b>01</b>/ 04 集 … 4节课带你从Skill从入门到毕业`）；
2. **H1 里唯一一个关键词加马克笔** `<span class="hl">…</span>`（最多一个词）；正文**一个区块最多一处** `<em class="acc">…</em>` 橙字；
3. **每个大部分开头一条色块章节条 `.ch-band`**：小字「第 N 部分」+ ≤12 字大白话标题 + 一张道具图（`.ch-prop`）+ 背景大数字（`.ch-glyph`）；颜色按轮换顺序取。

## 4. 组件速查（详细 HTML 写法看 `组件展示.html`）

| 组件 | 类名 | 什么时候用 |
|---|---|---|
| 页眉角标 | `.hud` / `.hud-ep` / `.hud-sep` | **每页必加** |
| 色块章节条 | `.ch-band` + `.is-orange/-purple/-teal/-yellow/-ink/-blue` | 每个大部分开头 |
| 黑金金句 | `.gold` + `.gold-small/.gold-big/.gold-sub` | 全页最重要的一句话，居中 |
| 白卡 / 当前卡 / 占位卡 | `.kv-card` / `.is-now` / `.is-ghost` | 「三件事」「两个问题」这类并列内容；先摆占位全貌再逐个点亮 |
| 对错对比 | `.cmp` + `.is-bad` / `.is-good` | 误区 vs 正解 |
| 对错勾 | `.chk.ok` / `.chk.no` | 清单逐条打勾 |
| 步骤路线图 | `.road` | 有先后顺序的方法 |
| 窗口 / 终端窗 | `.win` + `.win-bar` + `.win-body`；`.win.is-term`（重点行 `.hi`） | 截图、界面、提示词、命令 |
| 胶囊 | `.pill` / `.is-acc` / `.is-green` / `.is-soft` | 小标签 |
| 道具图 | `.prop` / `.is-float` / `.is-sm` / `.is-lg` | 一个区块 1–2 个；`robot_*` 系列可当「AI」的形象 |
| 印章 | `.stamp` / `.is-ok` | 一页最多 1 个，只给「退回 / 通过」结论 |

自动换肤、不用动的：`.ans-layer`（三层变三张白卡、第 1 张橙框）、`.fact-card`（白卡 + 圆形编号 + 浅色图框）、`.demo`（变视频同款「窗口」红黄绿三点）、`.anim-step` / `.anim-dot`、`.anim-verdict`（变黑金）、`.coach`、`.note`（变黄波点块）、`.foot`（变黑金）。

## 5. 用色铁律

1. **橙 `#FF4D1A` 是唯一的焦点色**：一个区块只亮一处橙。
2. 紫、青、蓝只当色块底色和知识卡片分类色，**不用于强调正文字**。
3. 绿 = 对，红 = 错，不混用。
4. **不用科技蓝当主色、不用蓝紫渐变、不用霓虹发光、不用玻璃拟态**。
5. 不用圈号 ①②③（编号用阿拉伯数字 + Inter 900 + 橙），不用斜体、不用下划线强调。

## 6. 动效

升起 rise（24px 淡入 0.6–0.7s）、弹出 pop（0.6 倍弹到 1，对错勾 / 印章 / 当前序号）、马克笔擦出（`.hl` 从左往右刷出）、道具漂浮 float（±8px 3.4s 循环）。skin.css 已全部实现且包在 `prefers-reduced-motion: no-preference` 里，**不要在页面里另写一套**。不做整页晃动、视差滚动、自动轮播。

## 7. 新道具怎么生

需要图库里没有的道具时，用 AI 生图（1:1），提示词 = 一句物体描述 + 固定风格尾巴：

```
[物体描述，英文，一句话，带颜色和视角，例如：A chunky retro desk calculator in cream and
orange with big rounded buttons and a blank grey display screen, slightly tilted,
three-quarter view.] Premium 3D clay render, soft matte materials, rounded friendly shapes,
high detail, warm soft studio lighting, gentle ambient occlusion. Centered with generous
margin, isolated on a perfectly flat solid pure green chroma key background, no shadow on
the background, no floor, no environment. No text, no letters, no numbers, no logos.
```

颜色优先奶油白、橙、暖棕、深青；生成后抠绿底、裁透明边、存透明 WebP（长边 480px）。新道具顺手存进 `assets/themes/dagongren/props/`，图库越用越全。
