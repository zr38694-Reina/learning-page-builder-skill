# 实战任务页（触发词路由 + 成页规范）

用户消息命中**实战任务类关键词**时，不走「学习页五问诊断」，按本文件做页面。

## 0. 触发与分型

**触发词**（命中任意一条即进入本规范）：

- 「实战任务」「实战任务学习页」「实战任务指导」
- 「任务描述」「给 AI 工具的任务」「把 prompt 复制给 AI 工具」
- 「一键复制任务」「自查清单 / 检查单 + 跑完看什么」

**先分型**（一句话问清或按上下文判，判不出默认 A）：

| 型 | 场景 | 做法 |
|---|---|---|
| **A · 独立任务页** | 这一页的使命就是「把任务发出去、跑完对检查单」 | 整页只有：紧凑头 + 任务区（本文件主角）。成页 donor：`/Users/reina/Desktop/智谱资料/实战任务学习页.html`（归档副本 `~/Desktop/课程页面html文字教程/实战任务学习页.html`） |
| **B · 学习页内嵌任务区** | 完整学习页（首屏三层 / 卡片 / 动画 / 总结都在）里**加一段**实战任务 | 只取本文件 §3 的任务区骨架，插在动画之后、知识总结之前；其余照 SKILL.md 正常流程 |

两种型共用 §3 的任务区骨架；A 型额外要做 §2 的裁剪与 §1 的首屏。

## 1. A 型 · 独立任务页骨架（自上而下只有三块）

```
<header class="hero">        ← 紧凑头：H1 + 一句引导（不占满一屏）
<section class="demo-sec" id="task">   ← 任务区：复制 prompt + 检查单 + 观察现象
<footer class="foot">        ← 照模板：品牌标识 + 一句「教学示意」声明
```

- **H1 不强制问句**（这是学习页问句规则的例外）：写成 `XX 实战任务指导` 或「实战任务指导」；`<title>` 同步。

## 2. A 型 · 从模板裁掉什么（照单删，别手软）

**JS**（一键复制：clipboard API + execCommand 兜底，照抄）：

```js
/* 实战任务描述：一键复制（clipboard API + execCommand 兜底） */
var copyBtn = $('copyPrompt');
var copyStatusEl = $('copyStatus');
function setCopyStatus(t) { if (copyStatusEl) copyStatusEl.textContent = t; }
if (copyBtn && $('taskPrompt')) {
  copyBtn.addEventListener('click', function () {
    var text = $('taskPrompt').textContent;
    function fallbackCopy() {
      var ok = false;
      var ta = document.createElement('textarea');
      ta.value = text;
      ta.setAttribute('readonly', '');
      ta.style.position = 'fixed';
      ta.style.left = '-9999px';
      document.body.appendChild(ta);
      ta.select();
      try { ok = document.execCommand('copy'); } catch (e) { ok = false; }
      document.body.removeChild(ta);
      setCopyStatus(ok ? '已复制。去 AI 工具里粘贴即可。' : '复制失败，请手动选中任务描述复制。');
    }
    if (navigator.clipboard && navigator.clipboard.writeText) {
      navigator.clipboard.writeText(text).then(function () {
        setCopyStatus('已复制。去 AI 工具里粘贴即可。');
      }, fallbackCopy);
    } else {
      fallbackCopy();
    }
  });
}
```

## 4. 三段文案怎么写

- **任务描述（`<pre>`）**：用户给的原文**逐字放入**，不改写、不排版、不补编号；没有原文时替用户起草，但要「可照着跑」——目标语言 / 库 / 输入规模 / 打印什么 / 禁随机数 / 注释语言逐条编号，收尾带一句「输出为什么可核对」。
- **检查单（`.check-list`）**：每条 = **查什么 + 怎么查（或错了会怎样）**，破折号后给核对动作或后果；写「实现上必须成立的性质」（投影不共用、维度算对、行和为 1、拼接顺序对），不写风格意见。
- **观察现象（`.obs-list`）**：每条 = 跑完**肉眼能看到**的变化（权重不同 / 改 Key 影响关注 / 改 Value 只改内容不改权重 / 输出是加权组合）；写现象不写结论，让用户自己核对。
- 首屏引导与 `<h2>`：围绕「复制 → 跑 → 对单」说，不写学习页的承诺式开场。

## 5. 已踩过的坑

1. **hero 100svh 把任务区顶到第二屏**——任务页必须按 §1 压 hero（`min-height:0`），交付前实测 `#task` 首屏可见。
2. **删动画块要删干净**：残留 `io.observe($('demo'))` 会因 `$('demo')` 为 null 直接抛 TypeError，整段 JS 全灭；删完 `node --check` 必跑。
3. **FAQ 结构化数据别留半截**：H1 不是问句时它永远对不上，整块删。
4. **复制状态是异步的**：点按钮后状态文字走 promise / 兜底，测试时读 `#copyStatus` 要稍等或重试一次，别把空字符串当失败。
5. **B 型内嵌时**任务区插在动画之后、知识总结之前，`id="task"` 不与动画 `id="demo"` 冲突；A 型才做 §2 全套裁剪。
