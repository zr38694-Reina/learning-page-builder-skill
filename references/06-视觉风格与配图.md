# 06 · 视觉风格与配图（方块科技风）

生成页共用一套视觉系统：**白底黑墨 + 科技蓝的「方块科技风」**。
本文档是这套系统的规范：设计令牌、母题规则、版式骨架、配图的画法与内嵌方式。
**换页不改风格**——风格只在「换品牌」时才动，且只动令牌（§1）。

---

## 0. 一句话总纲

- **母题是方块**：全页只有方块一种形状——直角代替圆角、填充色块代替描边卡片、无阴影、无渐变。
- **配色是「Sheet and biro」**：白底（`#fff`）+ 黑墨（`#111`）+ 一支科技蓝（`#1a4be0`）。
- **配图是几何插画**：浅灰底 + 网格 + 黑描边方块 + 蓝色点缀。不用照片、油画、渐变、写实素材。

---

## 1. 设计令牌（模板已内置）

亮色（`:root`）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#ffffff` | 页面底色 |
| `--surface` | `#f4f4f4` | 装置 / 教练卡底（浅灰块） |
| `--card` | `#ffffff` | 嵌套块（stage、counter、输入框…） |
| `--ink` | `#111111` | 文字与黑块（按钮、胶带、mark） |
| `--muted` | `#6b6b6b` | 次要文字 |
| `--accent` / `--accent-rgb` | `#1a4be0` / `26,75,224` | 品牌蓝（**两处必须同步改**） |
| `--accent-ink` | `#ffffff` | 蓝底上的文字色 |
| `--field` / `--field-ink` / `--field-muted` | `#111` / `#fff` / `#a3a3a3` | 页脚黑底 |
| `--hairline` | `#e6e6e6` | 细边框（句内小图等） |
| `--diagram-1` / `--diagram-2` | `#d9d9d9` / `#c2c2c2` | 方块图解的浅灰两级 |
| `--note-bg` / `--note-line` | `#efefef` / `#ffffff` | takeaway 便签 |

暗色（`prefers-color-scheme: dark` + `[data-theme="dark"]`，两处写法一一对应）：黑白互换、蓝色提亮为 `#5b7cff`（`--accent-rgb:91,124,255`）、`--accent-ink` 转深色。（暗色是模板自带的衍生变体；已交付的示例页只用到亮色。）

**换品牌色**：`--accent` 与 `--accent-rgb` 必须同步改；暗色变体里的对应两个值也一起改。其余令牌不用动。

字号 / 间距：`--fs-hero:clamp(38px,6.4vw,96px)`、`--fs-h2`、`--fs-statement`、`--fs-lead`、`--fs-body / --fs-table / --fs-sub / --fs-note`；`--pad`、`--shell:1240px`、`--gap-sec`。全部走 `clamp()`，不要写固定宽度。

## 2. 版式骨架（与 03 的八块一一对应）

| 块 | 类名 | 视觉要点 |
|---|---|---|
| 1 首屏 | `.hero` | 巨型 H1（全页最大字号）+ 副标题 + CTA + 配图（16:9，窄屏 4:3） |
| 2 一句话回答 | `.say` / `.statement` | 大字陈述（第二字号），句内可嵌 1–3 张小图 |
| 3 装置 | `.demo-sec` / `.demo` | 浅灰块装装置；下方贴教练卡 `.coach` |
| 4 原理 | `.how` | 方块带图解 `.flow`（散 → 收 → 齐）+ 三栏 `.how-cols` |
| 5 诚实提醒 | `.edge` / `.qa2` | 双栏连续阅读 |
| 6 知识卡片 | `.ai-facts` | 3 条；每条左侧一张 4:3 插画当项目符号 |
| 7 takeaway | `.note` | 便签（浅灰底 + 顶部黑块「胶带」） |
| 8 页脚 | `.foot` | 黑底；回场图 + 字块标记 `.mark` + 唯一一句声明 |

**块的顺序不可换**（装置在原理前、知识卡片在 takeaway 前）。

## 3. 配图位（4 处）与画布

| 位置 | 类名 | 画布（viewBox） | 显示 | 数量 |
|---|---|---|---|---|
| 首屏配图 | `.hero-plate` | **1400×1050** | 桌面 16:9 裁切、≤779px 4:3 | 1 |
| 句内小图 | `.inline-thumb` | **580×400** | 1.45em × 1em（跟着字号走） | 1–3 |
| 知识卡片插画 | `.ai-facts li` 内 | **560×420** | 4:3 | 3 |
| 页脚回场图 | `.return-plate` | **1200×900** | 4:3 | 1 |

- 首屏图会被 16:9 裁切（`object-fit:cover` / `slice`）——**构图主体放中间**，四周留够余量。
- 句内小图只有 1em 高：**元素少、形状大**，细线在这个尺寸会消失。
- 知识卡片三条各配一张；三张可以同构不同形（汇聚 / 对比 / 网络…）。

## 4. 插画规范（画新图时逐条照做）

1. **底色** `#f6f7f9`，叠 80px 网格（`#e8ebf2`，1px）——直接抄样例的 `<pattern>` 写法。
2. **墨色** `#111`：主形状用实心块或粗描边（描边 3–8，小画布取大值）。
3. **蓝色** `#1a4be0` 做主点缀（一图 1–3 处）；`#93aaf2` / `#dde5fb` 做浅色层。
4. **一图一个关系**：汇聚 / 分化 / 对比 / 序列 / 网络 / 拼装……一张图只讲一个动作。
5. 角落可加小十字装饰（`opacity:.25`），保持「工程图纸」感。
6. **不写字**：图里不嵌正文（小图会被裁切，文字交给 HTML）。
7. 每张图写 `role="img"` + `aria-label="示意图：…"`。
8. 无渐变、无阴影、无圆角、无照片。

---

## 5. 内嵌方式（单文件红线：图片全部内嵌，禁止外链）

- **首选：内联 `<svg>`** —— 直接放进 `figure / li / span` 里，后续可再编辑（改色、改形、复用）。
  - 同一页多张图时，`<pattern>` 的 **id 必须唯一**（如 `phHero`、`phC1`），重复 id 会互相串图。
  - 需要裁切的容器（hero、卡片、页脚）在 `<svg>` 上加 `preserveAspectRatio="xMidYMid slice"`；`<img>` 版由 CSS `object-fit:cover` 负责。
- **备选**：`<img src="data:image/svg+xml,…">`（URL 编码）或 base64 PNG（从外部工具导出的复杂图）。模板 CSS 对 `img` / `svg` 都支持。
- **体积参考**：16 张样例 SVG 合计约 35 KB；同样的图光栅化成 PNG base64 后约 130 KB——能用 SVG 就用 SVG。

## 7. 动效层（已内置，不要另起炉灶）

- `[data-rv]` 元素滚动入场（IntersectionObserver 加 `.in`；内联 `--d` 控延迟）。
- 首屏配图「快门」展开（`.hero-plate` 的 `shutter` / `settle`）。
- 原理方块带飞入（`.flow rect` 的 `--dx / --dy`）。
- 全部受 `prefers-reduced-motion` 保护（CSS 媒体查询 + `R()` 延时）。
  **页面里不要另加裸 `setTimeout` 动画**——时序一律走 `R(ms)`。

---

## 8. 反面清单（出现即返工）

- 圆角、阴影、渐变、玻璃拟态。
- 照片 / 油画 / 写实插画 / 外链图片。
- 多种母题混用（圆、三角、曲线花纹）。
- 调色板超出「黑 / 白 / 灰 / 蓝」——彩色只允许蓝一个色相。
- 图片里嵌正文文字。
- 给装置 / 配图另配一套动效（应复用 §7 的机制）。
