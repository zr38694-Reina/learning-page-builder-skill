# 小奈互动模式库（先选原型，再写卡）

> [!abstract] 怎么用
> 1. **圈点**：先在本页正文里圈**一个知识点**（一句话能说清、有对错或明确做法），这张卡只练它。
> 2. **查表**：在 §0 找到这个知识点对应的**互动原型**。
> 3. **照抄**：只读对应原型那一节，抄 `readContext` / `buildPrompt` 两段；prompt 用大白话写 3 行。
> 4. **验收**：过 §7 的六问。
>
> **提示词是写好的**：页面加载时 `refreshPrompt()` 调用 `buildPrompt()`，把 **3 行大白话**填进框；素材全部来自页面当前状态，**没有 `【】` 待填空**，学员打开即可一键发送。`refreshPrompt` / `resetPrompt` / 发送监听在 §2.2 给一份，**所有原型共用**，只换 `buildPrompt` 的业务文案。
>
> **一页只用一种原型。** 混用会让交付物退化成「一段既有表又有建议的话」。
>
> **还有第五种：开放提问型（三问卡）。** 如果这一页的目标不是考对错，而是让读者把刚在装置里看到的继续问下去，用三道开放问题，点哪道发哪道（见 §十）。它不占下面 13 种装置题型，也不套练习卡的 3 行 prompt。

## 〇、13 题型 → 4 原型 → 出题方式

| 题型 | 学员刚在装置里做完什么 | 原型 | 第 1 行出什么题 | 卡标题动作 |
|---|---|---|---|---|
| `01` 点选 + 计数器 | 调出一个数 | **诊断型** | 判断题 | 考我：该选哪一档 |
| `02` 滑块 + 单变量对照 | 拖出一个档位 | **诊断型** | 判断题 | 考我：该停在哪一档 |
| `04` 盲判 + 押注后核对 | 押了一边、看到对错 | **诊断型** | 判断题 | 考我：这次判断对不对 |
| `05` 自诊：选你停在哪 | 选了一个深度 | **诊断型** | 判断题 | 考我：停得够不够 |
| `03` 分步推进 + 终态对比 | 走完一条流程，停在某一步 | **对照型** | 对照题 | 考我：这一步实际发生了什么 |
| `09` 排序（拖回顺序） | 排出一版顺序 | **对照型** | 对照题 | 考我：这个顺序对不对 |
| `10` 拼装（零件组成品） | 拼出一版成品 | **对照型** | 对照题 | 考我：这块该放哪 |
| `11` 找错（定位坏点） | 指认一处坏点 | **对照型** | 对照题 | 考我：这个坏点找对没 |
| `13` 分支选择（走一条路） | 走完一条路径、看到代价 | **对照型** | 对照题 | 考我：这条路会走到哪 |
| `07` A/B 对比 | 选了一边、比过两版 | **改写型** | 改写题 | 考我：把这句改具体 |
| `12` 预算分配 | 分完一轮资源 | **改写型** | 改写题 | 考我：这轮预算怎么分 |
| `06` 播放（带代价帧） | 看完一次过程 | **产出型** | 分类题 | 考我：这一步先做哪件 |
| `08` 归类分堆（拖入两堆） | 把条目分完堆 | **产出型** | 分类题 | 考我：这条放哪堆 |

> [!important] 一张卡只练一个知识点
> 先在本页正文里圈**一个**知识点：一句话能说清、有对错或有明确做法（例：「Token 会按模型切碎」「占用到 75% 就该压缩」）。
> **不能拿「整页讲了什么」「五条流程」「这一章的重点」当练习对象**——那是复习，不是练习。
> 卡标题直接写这个知识点；prompt 第 1 行也只提它。换一个知识点 = 换一张卡，不扩写同一张。
> 提示词用大白话：不写「阈值 / 字段 / 归因 / 对照表」这类术语，像跟同事说话一样写。

## 一、先判断：学员手里剩下了什么

```text
学员刚在装置里做完的事
├─ 得到一个数 / 一个档位 / 一个判断      → 诊断型
├─ 走完一条流程 / 排好一版 / 定位一处坏点 → 对照型
├─ 得到一版可以修改的稿子 / 方案         → 改写型
├─ 看完一个过程 / 分完一堆条目           → 产出型
└─ 玩完只想继续追问「它到底怎么做到的」  → 开放提问型（三问卡，§十）
```

判据只有一条：**学员能不能把自己刚做的结果，原样交给小奈。**

交不出来（只剩「我看了」「我玩了」）→ 这张卡必然是空提示词框，先回去补装置状态，不要写卡。

反馈必须能直接抄走：第 2 行「我哪里对｜我哪里偏｜正确说法」，第 3 行「没答上就直接给答案」；四种原型共用。写不出这两句，说明卡还没写完。

## 二、诊断型（`01` / `02` / `04` / `05`）

**学员状态**：刚调出一个数字或选了一个档位，页面已经给出读数。
**这张卡只练**：一个判断点，例「占用到 75% 该不该压缩」。
**反馈固定**：我哪里对｜我哪里偏｜一句正确说法；答不上来就直接给答案。

### 2.1 卡片四句

| 位置 | 写法 |
|---|---|
| 标题 | 考我：什么时候该压缩 |
| 说明 | 她会拿页面上的轮数和占用率，出一道判断题，只考「什么时候该压缩」这一点。 |
| 提示词 | 3 行大白话：学哪个点 + 状态 + 题面 / 反馈 / 兜底；无待填空 |
| 按钮 | 发送给小奈教练 |

### 2.2 业务代码

```js
function readContext() {
  return [
    { k: '轮数', v: rounds.value + ' 轮' },
    { k: '占用', v: pct + '%' }
  ];
}

var COACH_CONFIG = {
  point: '上下文窗口什么时候会满',
  task: '判断题',
  hard: '数字是演示值'
};

function buildPrompt() {
  var state = readContext().map(function (x) { return x.k + '：' + x.v; }).join('；');
  return '我在学「' + COACH_CONFIG.point + '」。页面状态：' + state + '，请拿这段对话出一道' + COACH_CONFIG.task + '，先别解释；' + COACH_CONFIG.hard + '。\n' +
    '我回答后，你先说我哪里对、哪里偏，再给一句正确说法。\n' +
    '如果我没答上来，就直接告诉我答案，不要继续追问。';
}

/* —— 写好 / 重置 / 发送（所有原型共用，不用改） —— */
var promptDirty = false;

function refreshPrompt() {
  $('coachInput').value = buildPrompt();
  promptDirty = false;
}

function resetPrompt() {
  refreshPrompt();
  $('coachInput').focus();
}

$('coachInput').addEventListener('input', function () {
  promptDirty = true;
});

$('coachSubmit').addEventListener('click', function () {
  var input = $('coachInput');
  var prompt = (input.value || '').trim();
  if (!prompt) {
    $('coachStatus').textContent = '提示词为空，请先点「重置提示词」。';
    input.focus();
    return;
  }
  /* 框里已是完整提示词：直接发送，不再二次拼装 */
  sendCoachPrompt(prompt);
});

$('coachReset').addEventListener('click', resetPrompt);

/* 页面加载即写好 */
refreshPrompt();
```

**装置状态变化时**：在回调末尾加 `if (!promptDirty) refreshPrompt();`——学员没改过就自动同步，改过就不覆盖。**这一段所有原型共用**；下面 §3 / §4 / §5 只换 `readContext` 与 `buildPrompt` 的业务文案，不再重复贴。`buildPrompt()` 固定返回 **3 行**（`\n` 两个），不空行、不留 `【】`；素材从 `readContext()` 与页面当前展示取。

### 2.3 反馈样例

```text
我哪里对：知道要看占用率
我哪里偏：只看 75%，没看对话还要不要继续
正确说法：接近上限、还要聊同一话题时，先压缩再继续
```

## 三、对照型（`03` / `09` / `10` / `11` / `13`）

**学员状态**：刚走完一条流程、排出一版顺序、拼出一版成品，或指认了一处坏点。
**这张卡只练**：一个过程点，例「Token 是怎么切出来的」。
**反馈固定**：我哪里对｜我哪里偏｜一句正确说法；答不上来就直接给答案。

> [!warning] 这一类最容易写抽象
> 装置给的是**过程**，不是数值。如果 `readContext()` 只读「第几步」，prompt 里就没有具体对象，小奈只能回一段通用解释。
> **必须让页面交出一个具体素材**（演示原句 / 当前选项 / 当前一步），但也只考这个素材里的**一个点**；不要扩写成整条流程讲解。

### 3.1 卡片四句

| 位置 | 写法 |
|---|---|
| 标题 | 考我：这句话怎么切成 Token |
| 说明 | 她会拿页面上的「周末想去哪儿？」，出一道切分小题，只考「Token 怎么切」这一点。 |
| 提示词 | 3 行大白话：学哪个点 + 状态 + 题面 / 反馈 / 兜底；无待填空 |
| 按钮 | 发送给小奈教练 |

### 3.2 业务代码（本页实测版）

```js
function readContext() {
  var out = [];
  var scene = document.querySelector('.scene.on');
  var h3 = scene ? scene.querySelector('h3') : null;
  var line = document.querySelector('.input-line');
  out.push({ k: '演示原句', v: line ? line.textContent.trim() : '尚未开始' });
  out.push({ k: '演示进度', v: textOf('demoProgress') || '尚未开始' });
  out.push({ k: '正在讲的一步', v: h3 ? h3.textContent : '尚未开始' });
  return out;
}

var COACH_CONFIG = {
  point: 'Token 是怎么切出来的',
  task: '对照题',
  hard: '这是教学示意，切法因模型而异'
};

function buildPrompt() {
  var by = {};
  readContext().forEach(function (x) { by[x.k] = x.v; });
  return '我在学「' + COACH_CONFIG.point + '」。现在在' + by['演示进度'] + '，请拿「' + by['演示原句'] + '」出一道' + COACH_CONFIG.task + '，先别解释；' + COACH_CONFIG.hard + '。\n' +
    '我回答后，你先说我哪里对、哪里偏，再给一句正确说法。\n' +
    '如果我没答上来，就直接告诉我答案，不要继续追问。';
}
```

### 3.3 反馈样例

```text
我哪里对：知道要切成小块
我哪里偏：以为按字数切，其实按模型自己的切法，生僻词和符号会被切碎
正确说法：Token 不等于字，切法因模型而异
```

## 四、改写型（`07` / `12`）

**学员状态**：刚在 A/B 里选了一边，或在预算里分完一轮资源。
**这张卡只练**：一个改写点，例「怎么把模板话术写具体」。
**反馈固定**：我哪里对｜我哪里偏｜一句正确说法；答不上来就直接给答案。

### 4.1 卡片四句

| 位置 | 写法 |
|---|---|
| 标题 | 考我：把这句模板话术改具体 |
| 说明 | 她会拿页面上的 A 版，出一道改写小题，只考「怎么把话写具体」这一点。 |
| 提示词 | 3 行大白话：学哪个点 + 状态 + 题面 / 反馈 / 兜底；无待填空 |
| 按钮 | 发送给小奈教练 |

function readContext() {

```

我哪里对：知道模板句太笼统

正确说法：改成「今天 18:00 前原路退回」这种能核对的话
```

## 五、产出型（`06` / `08`）

**学员状态**：刚看完一次播放，或把条目分完堆。
**这张卡只练**：一个判断规则，例「这条消息该不该直接答」。
**反馈固定**：我哪里对｜我哪里偏｜一句正确说法；答不上来就直接给答案。

### 5.1 卡片四句

| 位置 | 写法 |
|---|---|
| 标题 | 考我：这条消息放哪堆 |
| 说明 | 她会拿页面上的分堆结果，出一道判断小题，只考「按什么规则选堆」这一点。 |
| 提示词 | 3 行大白话：学哪个点 + 状态 + 题面 / 反馈 / 兜底；无待填空 |
| 按钮 | 发送给小奈教练 |

## 六、五种题型表（写卡前先填这一行）

| 原型 | 第 1 行出什么题 | 什么时候用 | 反例 |
|---|---|---|---|
| **诊断型** | 判断题 | 页面在教一个判断 / 够不够 | 「帮我分析一下」 |
| **对照型** | 对照题 | 页面在教一个过程 / 顺序 / 结构 | 「指出容易出错的一步」 |
| **改写型** | 改写题 | 页面在教两版取舍 / 资源分配 | 「给点优化建议」 |
| **产出型** | 分类题 | 页面在教一次过程 / 一套分类 | 「总结一下重点」 |
| **开放提问型** | 三道开放问题（点哪道发哪道） | 页面适合让读者继续追问、没有对错可判 | A/B/C 选择题、「给出建议」式的空问题 |

四条硬规则（**开放提问型不适用**：它不判对错、prompt 只写「主题 + 问题 + 回答方式」，见 §十）：

1. **只练一个知识点。** 卡片标题和 prompt 第 1 行都只提这一个点；不拿整页或整条流程当练习对象。
2. **必须有页面素材或页面原值。** 全是通用词的问题，换个页面也能用，等于没用。
3. **用大白话。** 不写「阈值 / 字段 / 归因 / 对照表」这类术语；像跟同事说话。
4. **提示词固定 3 行、无待填空。** 第 1 行：学哪个点 + 状态 + 素材 + 题面 + 边界；第 2 行：哪里对 / 哪里偏 / 正确说法；第 3 行：没答上就直接给答案。不出现 `【】`、`____`、「改成你的」。

## 七、具体性六问（写完卡先过；开放提问卡改过 §10.6）

- [ ] **是不是只练一个知识点？** 标题和 prompt 第 1 行都只提这一个点；还在讲整页 / 整条流程 → 回去缩到一个点。
- [ ] **打开时框里是不是 3 行大白话？** 页面加载后已经写好知识点、状态、素材、题面、边界、反馈和兜底，且没有 `【】` 待填空；还是空框 → 回 §2.2 接 `refreshPrompt()`。
- [ ] **点发送是不是直接发框内全文？** 不再用 `buildPrompt()` 包一层；框里是什么就发什么。
- [ ] **遮住页面素材或状态**：prompt 还能执行吗？能 → 这一块是装饰，回 §3 / §4 补。
- [ ] **反馈能直接抄走吗**：看完能写进笔记 / 直接照做吗？不能 → 回 §4.5 改反馈句。
- [ ] **换成别的知识点还成立吗**：把知识点换成本页另一个点，这条提示词还成立吗？仍成立 → 写得太泛，重写标题与第 1 行。

## 八、抽象 → 具体（高频对照）

| ❌ 抽象写法 | ✅ 具体写法 | 为什么 |
|---|---|---|
| 把「逐块生成」套到你的用法上 | 考我：这句话怎么切成 Token | 标题要说清**练哪一个点** |
| 考我：这一页讲了什么 | 考我：这次判断对不对 | 一张卡只练一个知识点 |
| 我要让 AI 做的事是【】 | 页面上的「周末想去哪儿？」 | 素材从页面取，不要任务名 |
| 把整页内容拆成五步 | 只出一道对照题：Token 怎么切 | 出题聚焦一个点 |
| 先只问一个会改变结论的问题 | 先别给答案；我答完再告诉我哪里偏了 | 像跟同事说话，不写术语 |
| 页面演示状态：整段讲解文字 | 演示进度：第 3 / 5 步；正在讲的一步：变成向量 | 状态是学员看到的读数，不是教材正文 |
| 按「结论｜依据｜阈值｜下一步」给出 | 按「我哪里对｜我哪里偏｜正确说法」回我 | 反馈要能直接抄走，不能是名词摆设 |
| 提示词里只写「别乱编」 | 「别编造页面之外的信息」 | 禁令要能执行，不是表态 |
| 打开卡片是空框，让学员自己拼 | 加载即写好 3 行大白话，素材从页面取 | 学员要的是「打开就能发」 |
| 一张卡包住整页 / 整条流程 | 只圈一个知识点，其余留白 | 复习不是练习，一次只练一个点 |
| 提示词写成 5 段、10 行，还留【】 | 压成 3 行：出题+素材+边界 / 反馈 / 兜底 | 读者要一句能直接发的，不是待办清单 |
| 点发送时又用 `buildPrompt()` 包一层 | 直接 `sendCoachPrompt(框内全文)` | 框里已经是完整提示词，再包会重复 |
| 装置一变就覆盖学员改过的提示词 | `promptDirty` 标记；改过不覆盖，点重置才重建 | 学员的修改不能被动画吞掉 |

## 十、开放提问型（三问卡，不设标准答案）

> 这一型不考对错，也不要求学员先做判断。它只做一件事：把读者看完装置后**最想接着问的三个问题**摆在面前，点哪道就发哪道。

### 10.1 什么时候用

| 读者的状态 | 用哪种卡 |
|---|---|
| 刚做完一个判断 / 操作，能说「我选的是 X」 | **练习卡**（诊断 / 对照 / 改写 / 产出，§二–§五） |
| 刚看完一个过程，心里冒出「它到底怎么做到的 / 为什么会这样」 | **开放提问卡**（本节） |
| 页面没有装置，只是阅读内容 | **不配卡**（§一） |

判据：**这张卡要不要判对错？** 要 → 练习卡；不要，只想让读者继续追问 → 开放卡。**开放卡仍然只放在有装置的页面上**，它是装置之后的追问入口，不是聊天框。

### 10.2 三问怎么选

- **三条主线各一题**：整体机制 / 一个关键细节 / 能力边界。例：怎么接话 / Token 为什么对不上字数 / 为什么会编。
- **每题 8–24 字**，用「怎么 / 为什么 / 会不会」开头，读完就能直接问出口。
- **三题互相独立**：不能是同一件事的三种问法；也不做成 A/B/C 选项、填空或判断句。
- **必须能脱离页面被回答**：小奈看不到 iframe，问题本身要自带对象（「Token 为什么和字数对不上」，不是「这个为什么对不上」）。

### 10.3 卡面与交互

- 三个问题各是一个按钮（`.coach-ask`），**点哪道就发哪道**。
- 没有选项、没有选中态、没有「提交答案」、没有提示词预览框、没有「重新选」。
- 卡面只写「点一个发给她」这类动作说明；**不写「三道都没有标准答案」**这类元说明。
- 保留隐藏的 `coachInput` 与可见的 `coachStatus`，通信段照旧。

### 10.4 代码（可直接照抄）

```js
var ASKS = [
  '大模型是怎么把一句话变成回答的？',
  'Token 为什么和字数对不上？',
  '它为什么说得流畅，却也可能一本正经地编？'
];
var TOPIC = '大模型怎么接话';

function buildPrompt(q) {
  return '我在学「' + TOPIC + '」。\n\n' +
    '我想问：' + q + '\n\n' +
    '请用大白话回答：先给一句结论，再举一个例子，别展开成长篇。';
}

Array.prototype.forEach.call(document.querySelectorAll('.coach-ask'), function (btn) {
  btn.addEventListener('click', function () {
    var q = ASKS[parseInt(btn.getAttribute('data-q'), 10)];
    if (!q) return;
    var prompt = buildPrompt(q);
    $('coachInput').value = prompt;
    sendCoachPrompt(prompt);
  });
});
```

HTML / CSS 骨架见 `04` §6.7。

### 10.5 写坏了的样子

| ❌ 写坏了 | ✅ 改成 | 为什么 |
|---|---|---|
| 三个选项 A / B / C，让学员选正确答案 | 三道开放问题，点哪道发哪道 | 这是追问入口，不是测验 |
| 「下面哪种说法最接近？」 | 「它到底是怎么做到的？」 | 开放问题不预设答案 |
| 卡面写「三道都没有标准答案」 | 只写「点一个发给她」 | 元说明让卡变啰嗦 |
| 三个问题其实是同一件事 | 机制 / 细节 / 边界各一题 | 三题要覆盖三条主线 |
| 点「发送」前还要选中 / 确认 | 点问题本身就是发送 | 少一步，读者才愿意点 |
| prompt 里塞整页摘要、4 条 takeaway | 只留主题 + 问题 + 回答方式 | 问题自带上下文，摘要只会稀释它 |
| 问题里写「这个 / 它 / 上面说的」 | 「Token 为什么和字数对不上」 | 小奈看不到页面，指代必须写实 |

### 10.6 验收

- [ ] 恰好三道，都是开放问题，没有选项 / 标准答案 / 对错反馈。
- [ ] 点任意一道，只发这一道；没有选中态、没有二次确认。
- [ ] prompt 只含「学习主题 + 问题 + 回答方式」，没有页面摘要或装置读数。
- [ ] 三题分别覆盖机制 / 细节 / 边界，且都能脱离页面被回答。
- [ ] 卡面没有「没有标准答案」这类元说明。
