# 自检清单

交付前逐条过。**未过的项不要假装过了**——在回复里明确说明哪条没把握。

---

## A. 内容（路径与题型）

- [ ] **H1 是一个真问句**，且与结构化数据里的 Question 逐字相同
- [ ] **一句话回答在第一屏**（紧跟副标题），加粗了「定义 / 类比 / 后果」三处
- [ ] **装置在原理之前**：读者先看见现象，再读到命名
- [ ] **题型与内容性质匹配**（对照 `02-互动策略选型.md` 的判据表，能说出为什么是这一类）
- [ ] **装置自带论据**：不玩这个装置，就读不到本页的核心结论
- [ ] **takeaway 恰好 4 条**，顺序是 是什么 → 代价/边界 → 误区 → 我能做什么
- [ ] **有诚实提醒**：至少含「误区澄清」或「主动给软肋」之一
- [ ] **出门链接带理由**（「想去哪」+「为什么去」）；若本页是解法页，回指放在出门之前
- [ ] **空写测试**：把装置删掉，这页还剩多少？剩下的是「答案 + 原理 + 提醒」，够了

## B. 文案

- [ ] 副标题没有「你将学到…」这类空话，用的是三手法之一
- [ ] 一句话回答写了**四个落点**（首屏 / meta / 结构化数据 / 目录卡），四段各写各的
- [ ] 点出了「**哪个词在承重**」（给了模板或判据的地方）
- [ ] 页面里每一处**特意标记**（颜色、边框、高亮）都在正文里被命名过
- [ ] 反馈句式统一（先说结论 → 再说为什么 → 最后一条延伸判断）

## C. 工程

- [ ] **响应式**：窄到 320px 不横向溢出；优先用 `auto-fit / minmax` 而不是媒体查询；字号用 `clamp()`
- [ ] **iframe 嵌入**：响应式布局下无双重滚动条（靠 `auto-fit / minmax`，不靠高度上报）
- [ ] **`prefers-reduced-motion`**：所有时序归零（`beat()` 返回 0），退化成一口气展开
- [ ] **aria**：
  - 可点元素是 `<button>`（不是 `<div onclick>`）
  - 计数器 / 状态变化处有 `aria-live="polite"`
  - 选项卡组有 `role="tablist"` + `aria-selected` + `aria-controls`；或整组用 `aria-live` 播报
  - 滑块有 `aria-label` + `aria-valuetext`
  - 装饰性 emoji 加 `aria-hidden="true"`
- [ ] **定时器**：切档 / 重播前 `clearTimeout` 清空 `timers`
- [ ] **高频控件**（滑块、连续拖动）用 FLIP + 增量渲染，**禁止清空重绘**
- [ ] **零依赖**：无外链 CSS/JS/字体/图片；演示数据全部内联为 JS 常量
- [ ] **无网络请求**：页面离线可用
- [ ] 动画超过 3 秒的，提供了「↻ 再看一遍」

## D. 数据诚实

- [ ] **真数据标来源**（如「GPT-4o 家族 o200k 词表实测」）
- [ ] **近似值标用途**（如「演示费率，只用来感受量级」）
- [ ] **没有把演示值写成官方值**
- [ ] **越具体的地方越有免责**：凡是页面给出了具体数字 / 文件名的装置，正文或页脚有一句「这个数不是你的数」

## E. 小奈教练卡

- [ ] 卡片**贴着装置**（`anchor` 是演示容器），不是甩在页面底部
- [ ] **不是空聊天框**：能一键带入页面当前状态
- [ ] **带入成本低**：优先从页面读数；要手填就给**填空骨架**
- [ ] `prompt` 里含**硬约束**（对照 `04-小奈教练接入.md` §4 的表：页面教什么就防什么）
- [ ] **不在 iframe 时**：`coachStatus` 给出可见提示（不静默失败）；**不做**复制兜底 / 超时 / 重试
- [ ] 通信段（`复用代码开始` / `复用代码结束` 之间）**原样保留**，未被改坏
- [ ] 收到 `coach:ack` 即认为**宿主已接手**（不代表模型已回复）；回复只在对话里，页面不回显

## F. 交付说明

回复用户时说清四件事：

1. 文件路径（vault 内用 wikilink）
2. 诊断结论：**这一页用了什么题型、为什么是它**
3. 自检结果：**过了哪几条、哪条没把握**
4. 下一步：组内下一页 / 该补的出口链接

---

## 附：最常见的 6 个返工原因

| 症状 | 根因 | 修 |
|---|---|---|
| 学员看完不知道记住啥 | takeaway 超过 4 条 / 写成金句 | 回到 `03` §4 |
| 装置热闹但没学到东西 | 题型选错（用播放讲有对错的内容） | 回 `02` §1 判据表 |
| 页面像说明书 | 装置在原理之后 | 把装置提到原理前面 |
| 手机上一团乱 | 用了固定宽度 / 绝对定位 | 换成 `auto-fit + minmax` + `clamp()` |
| 页面里找不到小奈的回复 | 以为 `coach:ack` = 模型已回复 | 回复只在对话界面里，页面不回显 |
| 学员出门就乱问 | 小奈卡 prompt 没写硬约束 | 回 `04` §4 |
