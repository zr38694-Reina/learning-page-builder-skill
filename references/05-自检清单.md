# 自检清单

交付前逐条过。**未过的项不要假装过了**——在回复里明确说明哪条没把握。

---

## A. 内容（路径与题型）

- [ ] **H1 是一个真问句**，且与结构化数据里的 Question 逐字相同
- [ ] **H1 起名过关**（`03` §二）：**展示一个与 AI 相关的核心知识点**、口语、**主体 6–14 字**（双问句 ≤20 字）；不是名词短语、不带「一文讲清 / 详解」、不是只有「AI」没有知识点的泛标题
- [ ] **一句话回答在第一屏左栏**（H1 与副标题之下，与知识卡片同层），加粗了「定义 / 类比 / 后果」三处
- [ ] **首屏两栏版式正确**：桌面左栏一句话回答、右栏知识卡片；一句话回答没有变成 `hero` 下方横跨整页的独立区块；窄屏先答案、后卡片
- [ ] **H1 里的 AI 术语已在「一句话回答」开头用一句人话解释**（不默认读者懂；多个术语只解释核心那个，别写成术语表）
- [ ] **一句话回答已按单段在 1280px 桌面试排**：超过两行已拆成 2–3 个 `<p>`；不超过两行仍是单段
- [ ] **分段按语义**：每段至少一个完整句子，按「术语解释 → 机制 / 类比 → 后果」切；原句过长时已改写为 2–3 个完整短句，没有把一句话从中间掐断；没有用 `<br>` / 固定宽度按字符硬切，没有拆断术语、公式或 `.nb` 行内小图；第一段仍先解释 H1 术语
- [ ] **装置在原理之前**：读者先看见现象，再读到命名
- [ ] **题型与内容性质匹配**（对照 `02-互动策略选型.md` 的判据表，能说出为什么是这一类）
- [ ] **装置自带论据**：不玩这个装置，就读不到本页的核心结论
- [ ] **takeaway 恰好 4 条**，顺序是 是什么 → 代价/边界 → 误区 → 我能做什么
- [ ] **有诚实提醒**：至少含「误区澄清」或「主动给软肋」之一
- [ ] **每页都有「生活化举例」板块**：位置在原理之后、诚实提醒之前；三拍齐全（贴近 → 卡住 → 换法）、各优先 1 句（最多 2 句）；收尾有 `.life-map` 映射句（场景元素 → 本页术语），且点着本页具体内容（判据见 `03` §十二）
- [ ] **页面内没有任何超链接**：全页搜不到 `<a href>`；正文里没有「下一节 / 下一站 / 想看深入版 / 接着去哪儿」这类指向别处的话（红线 9 / `01` §2.3）
- [ ] **空写测试**：把装置删掉，这页还剩多少？剩下的是「答案 + 原理 + 提醒」，够了

## B. 文案

- [ ] **没有 AI 套话**：搜不到「不是…而是…」「本质上」「换句话说」「值得注意的是」「这意味着」「赋能 / 抓手 / 闭环 / 底层逻辑」（判据与改稿对照见 `03` §十）
- [ ] **句子够短**：平均 ≤25 字；超过 35 字的长句已拆；每段 ≤3 句
- [ ] **先例子后术语**：术语第一次出现时有一句人话解释，没有先抛词再解释
- [ ] **小白关（红线 10）**：做完**术语清点**——全文每个新概念的首现处都有解释（一句人话 + 类比），没有「读者需要另外查资料才能看懂」的词；装置文案、原理卡、诚实提醒里也逐处看过（判据与好例坏例见 `03` §十一）
- [ ] **首现解释 ≤2 句**、同一页只解释一次；没有把一个概念写成一小段（页面不是词典）
- [ ] **没有空泛承诺**：「让我们一起…」「你会发现…」「相信你一定能…」一律删
- [ ] **生活化举例的场景够具体但不堆料**：有一个名字或普通身份 + 一件物件 / 一个数字；没有「就像生活一样」这类万能场景；与首屏、原理栏的类比不重复（`03` §十二）
- [ ] **AI 小故事足够简单**：只讲一个动作 → 一个卡点 → 一次换法；三拍各优先 1 句，整块 60–100 字（上限 120 字）；读一遍能一句话复述
- [ ] **AI 小故事没有亲属称呼**：故事和标题里搜不到「你爸 / 你妈 / 爸爸 / 妈妈 / 你爷爷 / 你奶奶」等字眼；人物改用姓名或普通身份
- [ ] **念一遍像人话**：读出来像跟同事解释，而不是念稿
- [ ] 副标题没有「你将学到…」这类空话，用的是三手法之一
- [ ] 一句话回答写了**四个落点**（首屏 / meta / 结构化数据 / 目录卡），四段各写各的
- [ ] 点出了「**哪个词在承重**」（给了模板或判据的地方）
- [ ] 页面里每一处**特意标记**（颜色、边框、高亮）都在正文里被命名过
- [ ] 反馈句式统一（先说结论 → 再说为什么 → 最后一条延伸判断）
- [ ] **写卡前跑过 `scripts/scan_ai_concepts.py`**（`--page` + `--outline` + `--section`），据 A 段（本页命中清单）定卡
- [ ] **「知识卡片」在首屏右侧、与左栏一句话回答同排**：**本页命中的 AI 概念全收**（常见 3–5 条，**不限条数**，不足 3 条已按三层阶梯补）；**每条 1–2 句**；**都是概念**，没有动作、步骤、操作建议等非概念内容
- [ ] **长卡已切两张**：条目 **≥6 条**（或单张卡高超过首屏约 60%）时，卡切成两张 `.facts-page`、可横向滑动（`data-facts-switch` + 方块页码 01 / 02）；**≤5 条保持单张静态**，不硬切
- [ ] **切分只做视觉分组**：概念全收不变；两张卡里每条的 `<b data-term>` 都在，正文该出现下划线的词没丢（脚本从整块 `.ai-facts` 读词）
- [ ] **首屏没被卡片拉长**：切分后单张卡（含页码行）高度明显低于首屏；320px 宽下卡片区不横向溢出（滑动发生在卡内，不是整页）
- [ ] **翻页控件可键盘操作**：页码是 `<button type="button">` + `role="tab"` + `aria-selected` + `aria-controls`（外层 `role="tablist"`），左右方向键可切换；`prefers-reduced-motion` 下切换为瞬间、无平滑滚动
- [ ] **卡片以本页命中为主体（全收），不足 3 条时从 B 段（大纲本节）补**——扫描必须带 `--section`，别只扫本页
- [ ] **定义取自 `scripts/ai_concepts.json`**；扫描 D 段列出的未收录词**已补进词典**（没绕过词典临时编）
- [ ] **卡里至少 2 条点着本页或本课的具体内容**（把 H1 换掉仍成立 = 通用科普，重写）；**每条各讲一个概念**
- [ ] **本页与本课都没涉及的词不进卡**——词典是备选池，不是必须讲完的清单
- [ ] **候选不够时走完了三层阶梯**（`03` §1.6）：本页 → 大纲本节 → **相关概念兜底**（先 `--related` 查词典同类，词典没有才联网搜）
- [ ] **第 ③ 层补进来的词与本页主题强相关**（判据：把这个词放进别的页还成立吗？成立 = 热词科普，删掉）
- [ ] **联网搜来的新概念已按 7 字段补进 `scripts/ai_concepts.json`**，页面里没有现编的定义
- [ ] **同一批各页之间：补词不重复**（红线 8）：批量生成时用了 `--used <台账文件>` 逐页串起来；**补进来的词**与其它页无交集（本页命中的词照收，不受此限）
- [ ] 若某页不足 3 条：是先从 B 段换词、再走第 ③ 层仍补不齐，且已在交付说明里写明
- [ ] **每条的 `<b>` 都填了 `data-term`**（正文里的真实词形，别名用 `|` 分隔）；正文未出现的补词标不上属正常
- [ ] **正文里该词的第一个出现处出现了下划线**（打开页面第一眼就该看到；落在 H1 上是正常的）；同页只标一次
- [ ] **悬浮 / Tab 聚焦 / 触屏点按都能看到解析**，`Esc` 与滚动能收起；解析文字与卡内那条一致
- [ ] **下划线没落进装置、陪练卡和卡片自身**（脚本已自动跳过，人工抽查一处即可）；必要时用 `data-no-term` 关掉某一整块
- [ ] **320px 下气泡不溢出**（气泡 `max-width:min(330px,88vw)`，靠视口夹取 + 放不下自动翻到上方）
- [ ] **块序正确**（首屏（H1 + 副标题 + 左栏一句话回答 + 右栏知识卡片） → 装置 → 原理/清单卡 → 生活化举例 → 诚实提醒 → takeaway → 页脚）：答案在**左**、卡片在**右**；生活化举例在诚实提醒之前
- [ ] **跨模块一致性（红线 12）**：同一件事在首屏 / 知识卡片 / 一句话回答 / 装置 / 原理 / 生活化举例 / 诚实提醒 / takeaway / meta + 结构化数据里**一个口径**；写过主张台账（`03` §十三）
- [ ] **绝对化表述都有边界或限定**：搜过「永远 / 从不 / 一定 / 完全 / 免费 / 只有」，能加「默认 / 通常 / 在…下」的都加了，加不了的改掉
- [ ] **装置结论、原理区、takeaway 方向一致**；takeaway 与诚实提醒不互相打脸
- [ ] **数字 / 单位 / 术语全页一致**（同一个数不出现两个版本；同一概念不混用两种叫法）
- [ ] **meta description 与结构化数据 answer 跟正文同口径**（H1 或一句话回答改过时，这两处同步改）

## C. 工程

- [ ] **响应式**：窄到 320px 不横向溢出；优先用 `auto-fit / minmax` 而不是媒体查询；字号用 `clamp()`
- [ ] **iframe 嵌入**：响应式布局下无双重滚动条（靠 `auto-fit / minmax`，不靠高度上报）
- [ ] **`prefers-reduced-motion`**：所有时序归零（`R()` 返回 0），退化成一口气展开
- [ ] **aria**：
  - 可点元素是 `<button>`（不是 `<div onclick>`）
  - 计数器 / 状态变化处有 `aria-live="polite"`
  - 选项卡组有 `role="tablist"` + `aria-selected` + `aria-controls`；或整组用 `aria-live` 播报
  - 滑块有 `aria-label` + `aria-valuetext`
  - 装饰性 emoji 加 `aria-hidden="true"`
  - 正文术语的 `<span class="ai-term" tabindex="0" aria-describedby="termTip">` 是**气泡触发器**（不是按钮，属 tooltip 标准写法），由复用段自动生成——抽查一处存在即可，**不要**改成 `<div onclick>`
- [ ] **定时器**：切档 / 重播前 `clearTimeout` 清空 `timers`
- [ ] **高频控件**（滑块、连续拖动）用 FLIP + 增量渲染，**禁止清空重绘**
- [ ] **零依赖**：无外链 CSS/JS/字体/图片；演示数据全部内联为 JS 常量
- [ ] **无网络请求**：页面离线可用
- [ ] **卡片翻页复用段**：长卡页保留了页底「知识卡片翻页（复用段）」且未改动；短卡页没有它（或留着也无效果，不会有可见控件）
- [ ] **配图全部内嵌**：句内小图 1–3 张已配方块插画（**全页唯一配图位**；首屏不配图，知识卡片是纯文字）；无外链图片；插画无渐变、无阴影、无照片（规范见 `references/06-视觉风格与配图.md`）
- [ ] **场景图是 `.life-scene` 两格对照骨架**：方块母题、✓✗ 结论符号；入场动画只写在 `prefers-reduced-motion: no-preference` 下（静态与降级时完整显示、无裸 `setTimeout`）；≤600px 标签隐藏后，三拍文字仍能独立讲清故事
- [ ] **方块科技风与品牌资产未被改坏**：`--accent` / `--accent-rgb` 齐全且同步（默认 `#1a4be0` / `26,75,224`）；全页只有方块一种形状（**没有圆角卡片、阴影、渐变**）；`.coach-avatar` 与页脚 `.return-plate` 的奈势标识仍是**内嵌 base64**（没被换成外链图片或插画）
- [ ] 动画超过 3 秒的，提供了「↻ 再看一遍」

## D. 数据诚实

- [ ] **真数据标来源**（如「GPT-4o 家族 o200k 词表实测」）
- [ ] **近似值标用途**（如「演示费率，只用来感受量级」）
- [ ] **没有把演示值写成官方值**
- [ ] **越具体的地方越有免责**：凡是页面给出了具体数字 / 文件名的装置，装置下方 `.demo-note` 里有一句「这个数不是你的数」
- [ ] **页脚只留一句「教学示意」免责声明**：没有「内容依据《…》整理」这类来源标注（**内容出处不进页面**）

## E. 小奈教练卡（**仅互动页**；纯知识页整段跳过）

- [ ] **该配的配了、不该配的没配**：有装置的页面有卡；纯知识页**没有**卡，也没有 postMessage 通信代码残留（见 `04` §0）
- [ ] 卡片**贴着装置**（`anchor` 是演示容器），不是甩在页面底部
- [ ] **不是空聊天框**：能一键带入页面当前状态
- [ ] **带入成本低**：优先从页面读数；要手填就给**填空骨架**
- [ ] `prompt` 里含**硬约束**（对照 `04-小奈教练接入.md` §4 的表：页面教什么就防什么）
- [ ] **不在 iframe 时**：`coachStatus` 给出可见提示（不静默失败）；**不做**复制兜底 / 超时 / 重试
- [ ] 通信段（`复用代码开始` / `复用代码结束` 之间）**原样保留**，未被改坏
- [ ] 收到 `coach:ack` 即认为**宿主已接手**（不代表模型已回复）；回复只在对话里，页面不回显

## F. 交付说明

回复用户时说清四件事：

1. 文件路径（vault 内用 wikilink）
2. 诊断结论：**这一页用了什么题型、为什么是它**
3. 自检结果：**过了哪几条、哪条没把握**
4. 下一步：组内下一页 / 可继续深挖的方向

## 附：最常见的返工原因

| 症状 | 根因 | 修 |
|---|---|---|
| 标题没人点 / 像目录条目 | H1 写成名词短语、太长、跟 AI 无关 | 回 `03` §二 起名法 |
| 知识卡片漏词（本页出现的概念没进卡） | 没跑扫描，凭印象写卡 | 跑 `scan_ai_concepts.py` 拿 A 段，对照正文把命中的概念收全 |
| 首屏被知识卡片撑成一长列 | 条目 ≥6 条仍用单张长卡 | 回 `03` §1.3：切两张 `.facts-page`、加方块页码 01 / 02，横向滑动看 |
| 一句话回答孤零零横跨在知识卡片下方 | 仍在首屏外使用旧 `.say` 全宽区块 | 回红线 14：把 `.statement` 收进 `.hero-copy .hero-answer`，与右栏卡片同层起排 |
| 页面自相矛盾（前文说「永远准确」，后文又说「也会编事实」） | 各模块各写各的，没做跨模块对表 | 回 `03` §十三：拉主张台账统一口径，再把旧说法搜出来清掉 |
| 一句话回答变成一堵三四行的文字墙 | 只写了一个 `p`，没在桌面上按最终排版检查行数 | 回 `03` §4.2：超过两行就按语义拆成 2–3 段，用 `.statement p + p` 的段间距 |
| 知识卡片像百科词条 / 读者说「太难」 | 解析过短或过泛，或在一条里引了新词 | 回 `03` §1.3 的四条约束重写 |
| 正文里没有下划线 / 悬浮不出解析 | 卡里漏填 `data-term`（或填的不是正文里的写法） | 回 `03` §1.4，给对应概念补上词形 |
| 补词在好几页重复，读者觉得水 | 台账没串，补词撞了别页 | 回 `03` §1.5，用 `--used` 台账重跑，B 段换词 |
| 知识卡片空着 / 硬塞一个「大模型」之类 | 没走第 ③ 层兜底，或走了但选词跑题 | 回 `03` §1.6，先 `--related` 查同类，再联网搜并补词典 |
| 卡片里出现动作 / 步骤 / 操作建议 | 把「30 秒验证」之类的动作误当成概念 | 换成概念或删掉那条，见 `03` §1.3 |
| 学员看完不知道记住啥 | takeaway 超过 4 条 / 写成金句 | 回到 `03` §5 |
| 装置热闹但没学到东西 | 题型选错（用播放讲有对错的内容） | 回 `02` §1 判据表 |
| 页面像说明书 | 装置在原理之后 | 把装置提到原理前面 |
| 手机上一团乱 | 用了固定宽度 / 绝对定位 | 换成 `auto-fit + minmax` + `clamp()` |
| 页面里找不到小奈的回复 | 以为 `coach:ack` = 模型已回复 | 回复只在对话界面里，页面不回显 |
| 学员出门就乱问 | 小奈卡 prompt 没写硬约束 | 回 `04` §4 |
| 学员卡在某个词上 / 说「看不懂」 | 新概念没有首现解释（裸术语），或解释太长、太术语化 | 回 `03` §十一，做一次术语清点，逐词补解释 |
| 生活化举例像鸡汤、读者直接跳过 | 场景不具体、没有映射句、或和正文类比重复 | 回 `03` §十二：三拍写具体，收尾补「场景 → 术语」映射 |
| AI 小故事太绕 / 出现「你爸 / 你妈」 | 想写得完整，塞了多人、多转折和家庭关系 | 回 `03` §12.3：只留一个卡点，压到 60–100 字；人物换成姓名或普通身份 |
