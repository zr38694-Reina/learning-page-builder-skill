# learning-page-builder

> 把一个 AI / 科技话题，做成一页**可自学、可播放、可嵌入**的单文件 HTML 学习页。

产物固定是一个自包含 `.html`：内联全部 CSS + JS + 演示数据，**零依赖、可离线、可 iframe 嵌入、手机到桌面响应式**。

**这个 skill 的重点不是排版，是四件事：**

| # | 要保证的 | 具体指什么 |
|---|---|---|
| 1 | **学习路径** | 这页站在课程的哪一格、读者从哪进来、组内排第几。**页内不放链接、不写「下一站」**，续学靠页序与标题 |
| 2 | **可播放动画流程** | 用一个能播的过程讲清「发生了什么、怎么变的、结果如何」，每一拍都有字幕 |
| 3 | **小白视角** | 读者默认零基础，**每个新概念第一次出现就地解释**，不假设前置知识 |
| 4 | **概念准确** | 类比负责进门，边界负责不误导——不能把比喻写成实现 |

页面只是这四件事的容器。**先想清楚路径、动画结构、读者水平与概念边界，再动手写 HTML。**

## 四项最常被问到的设计规范

这四项是实测后固化的硬规范，改版时最容易找不到，先放这里：

| 设计项 | 规范要点 | 位置 |
|---|---|---|
| **知识卡片** | 一概念一卡：`.fc-num` 序号徽章 → 概念名 → `.fc-def` 解释 → 100×100 内联 SVG；宽屏 2 列，第 5 张 `grid-column:1/-1` 拉通，≤760px 单列 | [03 §1.3](references/03-页面骨架与文案.md#L54) |
| **圆角** | 全页只从三档取：`--r-card:14` / `--r-sm:10` / 控件 12；辅助档词块 8、句内小图 6；禁 `border-radius:0`；外大内小 14→10→8 | [06 §1.1](references/06-视觉风格与配图.md#L39) |
| **配色** | 只有一个色相，靠明度分层：卡片 `--c1…--c5`、首屏三层 `--f-c1/--f-c2`，亮暗两套成对；变量名不带颜色名；SVG 不写死颜色 | [06 §1.2](references/06-视觉风格与配图.md#L54) |
| **知识总结** | 一张居中便签两段：上段 **4 句黑字 + 实心方块**，下段 **2 条灰字 + 空心方块**，两段之间只留 18px 留白、**不写小标题**（旧 `.note-next` 已废），总 6 条过一遍去重 | [03 §五](references/03-页面骨架与文案.md#L426) |

## 四步流程

| Phase | 做什么 | 出口 / 闸门 |
|---|---|---|
| **1 诊断** | 判内容性质、页面粒度、页面间路径、读者进入姿态、本页配不配三问卡 | **只输出一份清单让用户点头**，不许先写代码 |
| **2 逐页文案** | 按五块骨架**先写成文字**，过「人话关」与「小白关」 | 文案过关才进 Phase 3 |
| **3 生成 HTML** | 用 `assets/page-template.html` 作外壳，把动画插进 `<!-- PATTERN SLOT -->` | 填完全部 `{{…}}` 占位符 |
| **4 自检** | 逐条过 `references/05-自检清单.md` | **未过的不交付** |

Phase 1 的确认闸不并入「快档」——省下的时间会在返工里加倍还回去。用户当次说「不用问，直接做」时才跳过（诊断压成 3 行写在回复开头）。

### 一页的五块骨架

| # | 块 | 要点 |
|---|---|---|
| 1 | 首屏 | H1 真问句（展示 AI 核心知识点 · 口语 · 主体 6–14 字）+ 左栏一句话回答 + 右栏知识卡片 |
| 2 | 副标题 | 术语祛魅 / 复述错误归因 / 畏难→反转→追加价值 |
| 3 | 一句话回答 | 第一屏给结论；超两行按语义拆成 2–3 个 `<p>` |
| 4 | 可播放动画流程 | 每拍有字幕、可播放/暂停/↻ 重看、进视野自动播一次可打断；**一次只显示一拍（切换式）**、进度点可点选跳转 |
| 5 | 知识总结 | 4 句黑字 + 2 条灰字，收在全页最后 |
| + | 小奈三问卡 | **条件项**：只有带可播放动画流程的页面才有，贴动画正下方 |

## 动画流程选型

| 内容性质 | 动画结构 | 文件 |
|---|---|---|
| 一个过程（输入 → 处理 → 输出） | 单线流程播放，代价帧放慢 | `patterns/06-播放动画.md` / `14-流转流程图.md` |
| 一组前后结果（差别只在一处） | 前后对照播放，只改一处结果翻转 | `patterns/15-前后对照动画.md` |
| 多步决策链（代价延迟显现） | 分支流程播放，走一条路看后果 | `patterns/13-分支选择.md`（改播放版） |
| 分层 / 逐层展开 | 逐层展开播放，逐节点点亮 | `patterns/03-分步推进.md` / `14-流转流程图.md` |

**默认只做播放型。** 旧 15 种互动题型仍在 `assets/patterns/`，只有用户明确要「可点 / 可拖」时才回查。

体量硬上限：整块 ≤450px @1280×800，播放键不独占一行，窄屏收成横向小链，`prefers-reduced-motion` 下直接显示终态。

## 知识卡片：取材脚本

写卡前先跑一次，拿「本页命中的概念清单」与草案：

```bash
# 单页
python3 scripts/scan_ai_concepts.py --page 本页.html --outline 本课大纲.md --section "本课在大纲里的那一节"

# 一批多页：串一个台账，补词不跨页重复（本页命中的词照收，不去重）
U=/tmp/本批概念台账.txt
python3 scripts/scan_ai_concepts.py --page p1.html --outline 大纲.md --section "环节 3" --used "$U"
python3 scripts/scan_ai_concepts.py --page p2.html --outline 大纲.md --section "环节 5" --used "$U"

# 候选不够时查同类概念
python3 scripts/scan_ai_concepts.py --related "注意力机制"
```

脚本只是素材，**卡片最终措辞由人拍板**。词典里没有的词，定好 1–2 句解释后顺手补进 `scripts/ai_concepts.json`（边用边长）。

## 16 条质量红线（写坏了要返工）

1. 先给结论，再播过程（不再另开原理卡）
2. 动画结构按内容性质选，不按个人偏好选
3. **takeaway 固定 4 条**：是什么 → 代价/边界 → 误区 → 我能做什么
4. 越具体的教学动画，越要写一句「这个数不是你的数」
5. 动画数据是教学材料，不是事实来源（声明写在 `.demo-note`）
6. 页脚只留「教学示意」一句，不写内容出处
7. 知识卡片 = 本页 AI 概念速览，定义取自词典；≥6 条切两张滑动
8. 同一批页面：本页命中的词照收，**补词不重复**
9. 页面内不放任何超链接、不写「下一站」（无 `<a href>`）
10. 读者默认零基础：新概念首现必解释
11. 动画流程必须自带解释（每拍有字幕）
12. 跨模块不许自相矛盾：同一件事全页一种说法
13. 一句话回答超过两行必须按语义拆段
14. 首屏固定两栏：一句话回答在左，知识卡片在右
15. 小奈三问卡只做三道开放问题：无选项、无标准答案、点哪道发哪道
16. **三条版式硬约束**：首屏占满第一屏（`100svh`）；副标题首句「我们将学习 ……」；动画一次只显示一拍（切换式，不叠一屏）

完整判据与坏例见 `SKILL.md` §二。

## 维护约定

**改规范要一处不漏。** 曾经的教训：只改了 `references/03` §五 正文，`SKILL.md` 骨架表、`03` 模块总表、`05` 旧自检、`assets/page-template.html` 四处仍是旧版式，下次生成页面直接照旧版写，然后被自检打回。

一条设计变更通常要同时落到：

- [ ] `SKILL.md` 的骨架表 / 红线 / 参考索引
- [ ] `references/` 里对应章节的**正文与模块总表**（同一文件里往往两处都写了）
- [ ] `references/05-自检清单.md` 的对应勾选项
- [ ] `assets/page-template.html` 的样式与结构（模板才是最容易被照抄的地方）

改完用 `grep -rn "<旧表述>" SKILL.md references assets` 全局搜一遍，确认没有残留。

另外两点：

- `references/03` 的章节编号从 §五 直接跳到 §七（历史遗留，缺 §六），引用时按标题找，别按编号数。
- 模板的品牌资产（小奈头像、奈势标识）以 base64 内嵌，换页不要动；换主题色时 `--accent` 与 `--accent-rgb` 必须同步改。
