> 适用：「做给打工人的AI入门系列」「4节课带你从Skill从入门到毕业」两个系列的 HTML 学习页 / 课件。

> 本文件替代原学习页模板里的视觉风格说明（`references/06-视觉风格与配图.md` 里「方块科技风：白底黑墨 + 科技蓝、直角、无阴影、无渐变」那套）。页面骨架、文案规则、脚本、红线**全部照旧**，只换外观。

## 0. 一句话风格

**暖白方格纸上的白色圆角卡片，墨黑粗体大字，一处橙色焦点；章节处整屏换成高饱和色块，金句处换成黑金暗场；配图是 3D 黏土质感的道具。**

关键词：纸白课件、粗黑体、橙色焦点、马克笔高光、色块翻页、黑金金句、黏土道具。

和原模板的差别：

| 项目 | 原模板（方块科技风） | 视频同款（本规范） |
|---|---|---|
| 页面底 | 纯白 `#FFFFFF` | 暖白方格纸 `#F2EEE5` + 44px 方格线 `#E4DED2` |
| 主色 | 科技蓝 `#1A4BE0` | 焦点橙 `#FF4D1A` |
| 形状 | 直角，无阴影 | 圆角 18px，2px 暖灰描边，柔和投影 |
| 标题字 | 系统黑体 800 | 思源黑体 900（最粗） |
| 卡片色 | 同一蓝色按明度分 5 档 | 橙 / 紫 / 青 / 蓝 / 墨 五种独立色 |
| 章节分隔 | 只有留白 | 整条高饱和色块（C） |
| 页脚 / 结论 | 纯黑 + 蓝按钮 | 黑金：近黑底 + 暖金光晕 + 金色按钮（B） |
| 配图 | 线框矢量 | 线框矢量加粗 + 3D 黏土道具图 |

## 1. 三种底：A 纸白 / C 色块 / B 黑金

视频的画面跟着内容的「角色」换底。网页照这个规则分配：

| 模式 | 用在哪 | 长什么样 | 占比 |
|---|---|---|---|
| **A 纸白课件**（默认） | 首屏、知识卡、演示动画、小奈三问、正文讲解 | 方格纸底，白卡，墨黑字，橙色焦点 | 约 75% |
| **C 整屏色块** | 开场、章节过渡、清单、练习、知识总结 | 整条高饱和色块 + 白色波点 + 超大白字/黑字 + 黄色下划线 + 漂浮道具 + 背后巨大半透明数字 | 每个大部分 1 条，全页 2–3 条 |
| **B 黑金暗场** | 金句、一句话结论、全页总结、页脚 | 近黑 `#0B0B0C` + 一团暖金光晕 + 象牙白大字 + 金色短横 | 每页最多 2 处（页脚算 1 处） |

规则：
- **三种都要出现**。只有 A 会显得像普通网页，失去视频的节奏感。
- **色块按顺序换色，相邻两条不同色**：橙 → 紫 → 青 → 黄 → 黑 → 蓝。同一页不要两条一样的颜色。
- 色块和黑金是「翻页」的感觉，不要在色块里塞长段落；正文回到 A。

在原模板骨架里的落点（`skin.css` 已经做好）：
- 首屏、知识卡片、演示、小奈三问 → A
- 每个大部分开头可插一条 `.ch-band` 色块章节条 → C
- 知识总结 `.note` → C（黄色块）
- 演示结论 `.anim-verdict`、页脚 `.foot` → B

### 2.3 B 黑金

| 名称 | 色值 | 用途 |
|---|---|---|
| 底 | `#0B0B0C` | 背景 |
| 光晕 | `rgba(100,76,34,.40)` 椭圆径向渐变 | 背景中偏上，只此一处渐变 |
| 象牙白 | `#EFE8D8` | 大字 |
| 暖灰 | `#8C8576` | 小字、说明 |

### 2.4 知识卡片五色（原模板的 c1–c5）

`c1` 橙 `#FF4D1A`、`c2` 紫 `#7B5CFA`、`c3` 青 `#23B89A`、`c4` 蓝 `#2F6BFF`、`c5` 墨 `#141416`。主题概念（第 1 张）固定橙色。

### 2.5 用色铁律

1. **橙是唯一的焦点色**。一个区块里只亮一处橙（一个重点词、一张当前卡或一个主按钮）。
2. 紫、青、蓝只当色块底色和分类色，不用来强调正文里的字。
3. 绿 = 对，红 = 错，不混用。
4. 不用科技蓝当主色，不用紫蓝渐变，不用霓虹发光。

## 3. 字体和字号

### 3.1 字体

| 用途 | 字体 | 字重 |
|---|---|---|
| 全部中文 | 思源黑体 / Noto Sans SC（`assets/fonts/NotoSansSC-500/700/900.woff`） | 500 / 700 / 900 |
| 数字、集数、编号 | Inter（`assets/fonts/Inter-var.woff`） | 800–900 |
| 代码、提示词、命令 | SF Mono / Menlo / Consolas | 400 |

回退顺序：`"Noto Sans SC","Source Han Sans SC","PingFang SC","Microsoft YaHei",sans-serif`。
注意：系统字体没有 900 这么粗，**字体文件要跟着页面一起发布**，否则标题会变细、不像视频。字体是 GB2312 常用字子集，生僻字会回退系统字体。

### 3.2 字重只有三档

- **900**：所有标题、卡片标题、章节大字、金句、知识总结里的加粗词
- **700**：标签、胶囊、按钮、角标、小字说明
- **500**：正文、导语

不用 300/400 细字，不用斜体。

### 3.3 字号表（网页）

| 层级 | 字号 | 字重 | 行高 | 视频里对应 |
|---|---|---|---|---|
| 章节大字（色块条） | `clamp(34px, 5.2vw, 76px)` | 900 | 1.15 | 过渡卡大字 140px |
| 页面主标题 H1 | `clamp(38px, 6.4vw, 96px)` | 900 | 1.12 | 片头「第 N 集」 |
| 金句（黑金） | `clamp(30px, 4.6vw, 64px)` | 900 | 1.25 | 金句 92px |
| 小节标题 H2 | `clamp(26px, 3.2vw, 44px)` | 900 | 1.2 | 页面标题 46px |
| 卡片标题 H3 | 18–22px | 900 | 1.3 | 卡片标题 25–32px |
| 导语 lead | `clamp(17px, 1.5vw, 20px)` | 500 | 1.6 | — |
| 正文 | 17px | 500 | 1.7 | 字幕 40px |
| 表格 / 卡片正文 | 15–16px | 500 | 1.7 | 卡片说明 19–22px |
| 标签 / 说明 / 角标 | 13–15px | 700 | 1.5 | 角标 22px |
| 大数字 | 按所在层级放大 1.5–2 倍 | Inter 900 | 1 | 数字 54px 橙 |

字距：标题 `letter-spacing: .01–.02em`（中文不要负字距）；角标、「第 N 部分」这类小字 `.12–.3em` 拉开。

## 5. 强调规则

视频里观众的视线靠两样东西引导：**字幕里重读的词变橙**、**标题里最重要的词刷一道黄色马克笔**。网页照搬：

- 标题（H1/H2）里**最多一个**词用马克笔：`<span class="hl">会写了</span>`
- 正文里**最多一个**词用橙字：`<em class="acc">写作文</em>`（或原模板的 `<b>` 在首屏结论卡里自动变橙）
- 数字是天然的重点：集数、步骤数、金额用 Inter 900 放大，可以上橙色
- 不用下划线、不用红字、不用感叹号来强调

### 6.3 版式习惯（来自视频）

- **先给结构，再逐个讲**：视频里先把「1 / 2 / 3」三张卡的位置摆出来（虚线占位），再一张张点亮。网页里并列内容先用卡片组摆出全貌。
- **标题是一句大白话**，不是名词短语：写「真用起来，卡在这两个问题」，不写「核心挑战分析」。
- **编号用阿拉伯数字 + 橙色**，不用 ①②③ 圆圈字符（字体里画得太细）。
- 左对齐为主；只有黑金金句居中。

## 7. 配图

### 7.1 道具图（首选）

视频里所有比喻都用 3D 黏土质感的道具：暖色、柔光、圆润、带暖棕色投影、透明背景。`assets/props/` 里有 60 张，`组件展示.html` 的「道具图库」能看到全部和文件名。

- 放在色块章节条右侧（`.ch-prop`）、卡片角落、标题旁边
- 一个区块最多 1–2 个道具；加 `.is-float` 会缓慢漂浮（3.4 秒一个来回，±8px）
- 机器人系列（`robot_*`）可以当「AI」的形象：思考、打字、提问、出错、点赞、挥手

需要新道具时，用 AI 生图（1:1），提示词 = 一句物体描述 + 固定风格尾巴（和视频生道具用的是同一段）：

```
[物体描述，英文，一句话，带颜色和视角，例如：A chunky retro desk calculator in cream and
orange with big rounded buttons and a blank grey display screen, slightly tilted,
three-quarter view.] Premium 3D clay render, soft matte materials, rounded friendly shapes,
high detail, warm soft studio lighting, gentle ambient occlusion. Centered with generous
margin, isolated on a perfectly flat solid pure green chroma key background, no shadow on
the background, no floor, no environment. No text, no letters, no numbers, no logos.
```
物体颜色优先选奶油白、橙、暖棕、深青；生成后抠掉绿底，裁掉透明边，存成透明 WebP（长边 480px 够用）。

不要用：扁平矢量插画、线性图标、emoji 当主图、真人照片、写实大脑（表示「模型」用机器人）、纸币图案（表示钱用金币 `coins`、价签 `price_tag`）。

### 7.2 知识卡片里的线框示意图

原模板的 `.fc-fig` 线框图可以继续用，`skin.css` 会自动：线宽加粗到 3.2px、矩形和圆形填白色、颜色跟着卡片色走。画新图时：
- 只画一个关系，图里不写字
- `stroke="currentColor"`，圆角 `rx="4"` 以上
- 形状要「胖」：少而大，不画细碎小件

## 8. 动效

视频的动作是「快进慢停」+「弹一下」+「一直轻轻在动」。网页只取克制的部分：

| 动作 | 规格 | 用在哪 |
|---|---|---|
| 升起 rise | 从下方 24px 淡入，0.6–0.7s，`cubic-bezier(.16,1,.3,1)`；同组错峰 70–90ms | 所有 `[data-rv]` 区块（原模板已有，换了缓动） |
| 弹出 pop | 从 0.6 倍弹到 1，0.45s，`cubic-bezier(.34,1.56,.64,1)` | 对错勾、印章、当前步骤的序号 |
| 马克笔擦出 | 高光从左往右刷出，0.6s，延迟 0.35s | `[data-rv]` 里的 `.hl` |
| 漂浮 float | 上下 8px、轻微摆动 ±1.2°，3.4s 循环 | 道具图 |
| 悬停 | 上移 2–3px + 投影变大 | 卡片、按钮 |

- 全部包在 `prefers-reduced-motion: no-preference` 里，对动效敏感的用户直接看到成品
- 不做整页晃动、视差滚动、自动轮播

## 9. 暗色模式

暗色 = **B 黑金**：近黑底、象牙白字、焦点色从橙换成金 `#D4B26A`，方格线变成极淡的金色。`skin.css` 已按原模板的两种写法（`prefers-color-scheme` 和 `data-theme="dark"`）各写一份。

## 10. 别这样做

1. 纯白底、直角卡片、无阴影（原模板风格）
2. 科技蓝当主色、蓝紫渐变、玻璃拟态、霓虹发光
3. 标题用细体或系统默认字重
4. 一屏里出现三四个橙色重点
5. 用 emoji、线性图标、扁平插画、真人照片当主配图
6. 色块条里塞长段落
7. 全页只有纸白，没有色块和黑金（节奏会和视频对不上）
8. 一页两条同色色块，或者色块紧挨着黑金
