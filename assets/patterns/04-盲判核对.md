# 04 · 盲判 + 押注后核对

**何时用**：内容**能证真假**——有一批条目，每条要么可信要么可疑，且有客观答案。
**心理机制**：承诺一致 + 预测误差（我先押注，再看答案）。
**强度**：这是全套题型里**最强**的一种，因为**押注之后错误才疼**。
（要「整篇里找出一处坏点」用 `11`；要「体会延迟后果」用 `13`——两者也强，但押注的是别的东西。）

> 与「自诊」（`05`）的分界：**有客观对错 → 盲判；没有对错只有深浅 → 自诊。**
> 用盲判讲一个没有客观答案的内容，学员不知道自己在押什么注。
> 与「归类」（`08`）的分界：**判真假 → 盲判；判归属 → 归类。**
> `04` 的每条断言**有对错**；`08` 的每个类别**都成立**，学员只是分不清某条该进哪个类别。

## 数据形状

```js
var DATA = [
  { id: 'a', text: '开头那句 0.47 升…',        kind: '数字',     ok: true  },
  { id: 'b', text: '2019 年那次升级…',         kind: '时间线',   ok: false },
  { id: 'c', text: '地毯增压模式下…',           kind: '参数名',   ok: false },
  { id: 'd', text: '滤网建议 90 天更换…',       kind: '冷门材料', ok: false },
  { id: 'e', text: '支持手机云同步…',           kind: '功能有无', ok: false }
];
```

## 关键手法一：押注才见答案

右侧「核对结果」初始为空。点某处后，如果**还没做判断**，只显示一句：

> 先选「可信」或「可疑」，做出判断后这里会显示核对结果。

只有点了底部的 `可信` / `可疑`，才 `reveal()` 出真相。

```js
function reveal(id) {
  var item = DATA.find(function (x) { return x.id === id; });
  if (!judged[id]) {
    resultBox.textContent = '先选「可信」或「可疑」，做出判断后这里会显示核对结果。';
    return;
  }
  resultBox.textContent = judged[id] === item.ok
    ? '✓ 判断一致。' + (item.why || '')
    : '✗ 差一点——' + (item.why || '');
}
```

**「点开即看答案」变成「押注才见答案」——多这一道闸，就把浏览变成了测验。**

## 关键手法二：埋一真（最容易被忽略，也最重要）

**反例集里必须留一个正确答案。**

- 五处全假 → 学员学到一条**更粗暴的错误规则**：「数字都不可信」。
- 埋一真 → 才逼出页面真正想教的**分级判断**。

而且**真的那一处最好恰恰是最像「精确＝可靠」的那个**（`0.47 升` 这样的精确小数）。

正文里那句判断句要和它互为注解：

> 「这五类**不等于一定是错的**，它们表示『先别直接写进笔记』。」

做法：**先写下本页最重要的那句判断，然后把它设计成一道题的特例。**

## 关键手法三：进度 → 通关 → 命中率

```js
// 每开一处 +20%，全开才触发总结
bar.style.width = (opened.size / DATA.length * 100) + '%';
if (opened.size === DATA.length) paintSummary();

function paintSummary() {
  var hit = DATA.filter(function (d) { return judged[d.id] === d.ok; }).length;
  summary.innerHTML =
    '你判断了 <b>' + DATA.length + '</b> 处，其中 <b>' + hit + '</b> 处与核对结果一致。';
}
```

第 1 条把「答题数」变成「**命中率**」——**完成感来自对比自己，不是来自教师评语。**

## 关键手法四：难度开关（标签可折叠）

同一页适配两种水平：

| 档 | 难度 | 效果 |
|---|---|---|
| `先隐藏类别，自己判断`（默认） | 难 | 你得先自己归类 |
| `显示每一处的类别` | 易 | 直接告诉你这是「时间线」还是「冷门材料」 |

切换时用 **FLIP**：先记旧坐标 → 插入标签 → 反向位移 → 放开，让已高亮的那处**自己滑到新位置**，不丢视觉焦点。

## 关键手法五：节拍依据「真假」而非「步序」

| 片段 | 时长 |
|---|---|
| 开场 | 900ms |
| **真的那一处** | 1500ms（快过） |
| **编造的几处** | 2100ms（多看） |
| 最后一处 | 2800ms（定格） |

真话快过、假话多看、收尾定格。

## 自动播放：播一次，被打断就不抢戏

```js
var played = false, touched = false;

window.lessonOnView(demo, function () { if (!played) { played = true; play(); } }, 80);
// 只要用户自己点过任何一处，自动播放就不再触发
demo.addEventListener('click', function () { touched = true; });
```

播放中未选中项降到 `opacity:.45`，**自动播放也能「聚焦一处」**，不会五处一起闪。

## 陷阱

- **不埋真** → 教出一条错的规则。
- **点开即看答案** → 退化成浏览，学员不会先思考。
- **用「对/错」当反馈词** → 换成「判断一致 / 差一点」，语气从判词变成信息。
- **让用户答错后重来** → 目标是**让解释被读到**，不是让学员答对。重试会让人跳过解释去试答案。
