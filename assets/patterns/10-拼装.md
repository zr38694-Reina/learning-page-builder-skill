# 10 · 拼装（从零件库组一个成品）

**何时用**：内容可被**拆成零件**，不同组合 → 成品质量不同——prompt、方案、话术、提纲、配置。
**心理机制**：建构 + 缺失感（少写一句约束，输出立刻跑偏）。
**判据**：存在「**缺一块就垮**」的关键零件——不装它，成品会当场失效，**且能看见它失效**。

> 与「A/B 对比」（`07`）的分界：**`07` 是二选一（两档都是别人写好的），`10` 是多选组合（成品是学员自己搭的）。**
> `07` 让学员**比较**两个成品，`10` 让学员**承担**一个成品。
> 只有 `07` 能给「哇，这版好太多」；只有 `10` 能给「原来是我少写了那一句」。

---

## 结构

```
[ 零件库 ]      角色 · 任务 · 约束 · 格式 · 示例        ← 点了就进装配台
──────────────────────────────────────────
[ 装配台 ]      你拼出来的那一句（实时长出文字）
──────────────────────────────────────────
[ 试运行 ]      用这句去跑那个固定案例 → 出结果
```

**关键：必须有「试运行」。**
没有试运行，拼装就只是造句；有了试运行，**缺零件的后果才能被看见**。

---

## 实现要点

```js
var PARTS = [
  { id: 'role',   text: '你是一名差旅报销审核员',              must: false },
  { id: 'task',   text: '判断这张发票能不能报',                must: true  },
  { id: 'constr', text: '只依据《差旅费管理办法》回答',        must: true  },
  { id: 'format', text: '用「能报 / 不能报 + 依据条款」回答',  must: true  },
  { id: 'ex',     text: '例如：「能报，第 3 条」',             must: false }
];

function run() {
  var missing = PARTS.filter(function (p) { return p.must && !picked[p.id]; });

  // 输出不是「分数」，是一段会跑偏的话——让学员自己读到问题
  out.textContent = missing.some(function (m) { return m.id === 'constr'; })
    ? '一般来说，企业差旅报销标准会根据职级和城市有所不同，建议您咨询公司的财务部门。'  // ← 正确但没用
    : '不能报。依据：第 3 条，住宿每晚不超过 500 元。';
}
```

**缺 `constr`（约束）时输出的必须是「正确但没用的场面话」**，而不是「AI 胡说」——
真实痛点常常就是「用正确的话说没用的事」（选材原则同 `07`）。

---

## 三条手法

### ① 关键零件给「视觉缺口」，不给提示文字

装配台上，必填零件的位置**从一开始就留一个虚线空槽**（同 `03` 手法 ③「缺失项全程挂着」）。
学员不需要被告知「你还缺一句」——**他看得见那儿空着**。

### ② 每加一个零件，输出**当场重跑**

不要点「生成」才看结果。**每装一块就跑一次**——学员才能把「我加了什么」和「结果变了什么」对上。
（这本质上是一次**单变量对照**，只是自变量由学员自己加。）

### ③ 收尾给「最小可用组合」

跑通之后，明示**最少需要哪几块**：

> 最小可用组合：**任务 + 约束 + 格式** 三块。
> 角色和示例是加分项——它们让输出更稳，但不是缺了就垮的那一块。

**这一句才是迁移点**：学员记住的不是这个 prompt，而是「任何 prompt 都至少要这三块」。

---

## 节拍

| 动作 | 时长 |
|---|---|
| 零件入台 | 200ms |
| 输出重跑 | 350ms（要有「重新想了一下」的感觉） |
| 最小组合揭示 | 400ms |

- **不做自动播放**（同 `08` / `09`）。

---

## 陷阱

- **没有试运行** → 拼装退化成造句，缺零件的后果不可见。**这是本题型最致命的漏做。**
- **零件库太大（> 8 个）** → 学员挑花眼，试不动。**5 块左右最舒服**，其中 2–3 块是关键件。
- **输出直接给「得分 80 分」** → 分数说了结论，学员就不读那段话了。**给一段会跑偏的文本。**
- **关键件的缺失靠文字提示**（「记得加约束哦」）→ 改成视觉空槽（同手法 ①）。
- **拼完不给最小组合** → 学员学会的是这一个 prompt，不是那三块结构。
