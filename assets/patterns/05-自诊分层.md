# 05 · 自诊：选你停在哪

**何时用**：内容只能**分层**，**没有正确答案**——「你现在会停在哪一步」「你的做法属于哪一层」。
**心理机制**：自省（我停得太早了）。
**判据**：层与层之间递进的是「**动作颗粒度**」，不是「对错」。

> 与「盲判」（`04`）的分界：**没有对错 → 自诊。** 别硬造一个正确答案。

---

## 三个可复用的设计手法

### ① 三层的差异是「动作颗粒度」，不是「对错」

| 层 | 动作 | 递进的是 |
|---|---|---|
| 1 | **收下**答案 | 接受 |
| 2 | **圈出**未知条件（但停在感觉里） | 识别 |
| 3 | **写出**下一问（变成可执行动作） | 转化 |

层层递进的是「**把模糊担心转化为现场动作**」的程度。
这个阶梯正好对应从「识别问题」到「形成可验证假设」的推进。

### ② 第 2 步给「代价」，且停得最久

每层的第 2 步都是「**什么都不多做的代价**」——这就是让学员产生自省的关键帧。

```js
var HOLDS = [1400, 2800, 2300];   // 故意不匀速：代价帧停最久
```

**播放节奏故意不匀速**，其他帧加快，代价帧放慢。

### ③ 让「缺失项」全程挂着，最后才点亮

那条「还缺的一句」**从第一步就摆在屏幕上**（暗的），只有走到最后一步才高亮发光：

```js
// 这条从第一步就渲染，但只有最后一步加 .lit.glow
if (stepIdx === 2) missingLine.classList.add('lit', 'glow');
```

视觉上的「一直缺一块」比文字说明更能制造张力。

---

## 结构：三层 × 三步 = 9 个状态

```js
var TIERS = {
  1: [ { head:'你拿到了一份能用的菜单', cap:'…', body:'…' },
       { head:'直接照着菜单下单',     cap:'…', body:'…' },
       { head:'接下来先找未知条件',   cap:'…', body:'…' } ],
  2: [ /* … */ ],
  3: [ /* … */ ]
};
// 每层第 3 步固定是「接下来该写哪一句」——把演示收束成动作
```

控件：`播放` / `单步` / `重置` 三个按钮 + 三个层级按钮（`data-tier`）。
**9 个状态的多状态演示才值得给「单步 / 重置」**；3 秒的动画不值得。

---

## 文案要求

- 题目文案用**祈使 + 自选**：「**选择你现在会停下的位置**」，副标「点选一层，看看这次会发生什么，以及下一句该怎么写」。
- **不要写「正确答案是第三层」。** 三层都是真实存在的状态，页面只是让你看清自己停在哪、以及停在那里会付出什么。
- 文案硬编码为常量数组，页脚标注「教学示意：为演示所写，不对应某个模型的真实输出」。

---

## 陷阱

- **暗示第三层才是对的** → 自诊退化成测验，且学员会为了「答对」而假装。
- **三层差异写成「多/少」** → 应该是**动作颗粒度**的差异（接受 → 识别 → 转化）。
- **9 个状态全部匀速** → 代价帧失去重量。**必须不匀速。**
- **没有「重置」** → 学员想再看一遍代价帧时只能刷新页面。
