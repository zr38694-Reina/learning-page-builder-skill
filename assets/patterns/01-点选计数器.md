# 01 · 点选 + 计数器

**何时用**：内容有**可计量的单位**——钱、字数、颗数、秒数、步数、条数。
**心理机制**：量级震撼（原来这么费 / 原来这么多）。
**判据**：能数出来，但读者**凭直觉估不准**。估得准的内容不要用这个题型。

---

## 数据形状

```js
var RATE_PER_K = 2;   // 演示费率（近似值 → 必须标用途）
var ITEMS = [
  { label: '中文短句', text: '今天天气真不错', units: ['今','天天','气','真','不错'] },
  { label: '英文句',   text: 'The weather is nice today',
    units: ['The',' weather',' is',' nice',' today'] }
];
```

**`ITEMS` 是精心设计的对照组，不是随便凑的例子。** 学员通过对比自己发现结论：

| 对照组 | 学员自己看出来的 |
|---|---|
| 中文句 vs 英文句 | 「表达同样的意思，中文消耗更多」 |
| 带数字符号的句子 | 「字数 ≠ 单位数」 |
| 长单词被切开 | 「机器不按人的语感切」 |

结论不要写在选项里，**写在正文里命名它**。

## 实现

见 `../page-template.html` 的 `PATTERN SLOT`（已实现：3 个选项 + 逐个弹出 + 三个计数器实时跳动）。

要点：

```js
chips.forEach(function (chip, k) {
  timers.push(setTimeout(function () {
    chip.classList.add('show');
    $('cB').textContent = k + 1;          // 计数跟着跳
    $('cC').textContent = fmt(k + 1);     // 账单跟着跳
  }, beat(160 * (k + 1))));
});
```

---

## 三条必须遵守

1. **数字要动，不要静态展示总数。**
   静态总数是「结论」，跳动是「过程」。这一页要展示的是「每写一个字都在花钱」**这个感觉**，不是「这句话值 0.01 厘」**这个数**。

2. **真数据标来源，近似值标用途。可以混用，不能混标。**
   ```html
   <p class="demo-note">切分为 <b>真实数据</b>（GPT-4o 家族 o200k 词表实测）；
     费率为 <b>演示值</b>（每千颗约 2 厘），只用来感受量级，换别的模型会不同。</p>
   ```

3. **越具体，越要加免责。** 给了具体数字的装置，正文或页脚必须有一句「**这个数不是你的数**」，
   并且**把它写进小奈教练卡的 prompt 硬约束**。

---

## 节拍

| 单位数 | 每颗间隔 | 总时长 |
|---|---|---|
| 5 颗 | 160ms | ~0.8s |
| 10 颗 | 160ms | ~1.6s |
| 15 颗 | 160ms | ~2.4s |

超过 20 颗要缩短间隔（`120ms`）或分批出现，否则学员会等烦。

---

## 陷阱

- **无反馈的点击**（点了只是高亮，数字不变）→ 装置白做。
- **把结论写进选项文案**（「英文句（更省）」）→ 学员不用对比就知道答案，失去发现感。
- **重播不清定时器** → 连点两次，两轮的 chip 会交叉出现。
