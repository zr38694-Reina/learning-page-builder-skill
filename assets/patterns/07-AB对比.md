# 07 · A/B 对比（默认播坏的那档）

**何时用**：内容需要让人**产生倾向**——两种做法，想让学员心疼其中一种的代价。
**心理机制**：对比 + 失去厌恶。
**判据**：两档都有道理，但**一档的代价是隐藏的**（不演示就看不出来）。

---

## 关键手法一：顺序就是观点

**页面加载就播坏的那一档。**

```js
btnBad.addEventListener('click', function () { play('bad'); });
btnGood.addEventListener('click', function () { play('good'); });
play('bad');   // ← 脚本末尾：一加载就播失败版
```

学员不是从零选择看哪档，而是**先被迫看完「多问三句有多烦」，再带着刚建立的不耐烦去点另一档**。

**先让你经历代价，再给你解药。** 这是失去厌恶的直接应用。

---

## 关键手法二：两档的步数不对等，差的几步全是「浪费」

| | 步数 | 坏步骤 | 收尾徽章 |
|---|---|---|---|
| 😵 坏的那档 | **9 步** | 4 步 `.waste` | `跑了 4 趟 · 问了你 3 次` |
| 📋 好的那档 | **5 步** | 0 | `1 趟搞定 · 0 次打扰` |

**失败步骤的样式 = 红 + 虚线**：

```css
.step.waste{
  background:var(--danger-soft);
  border:1px dashed rgba(220,38,38,.35);
}
```

**颜色说「这是失败」，虚线说「这一步不是必须存在的」。**
虚线是「被设计出来的浪费」——这个细节比红色本身更有信息量。

---

## 关键手法三：收尾把体验变成两个数字

```js
var MODES = {
  bad:  { badge: '跑了 4 趟 · 问了你 3 次',
          verdict: '每做一步就回来确认一次——你比自己动手还累。' },
  good: { badge: '1 趟搞定 · 0 次打扰',
          verdict: '带着经验出门，一趟干完。' }
};
```

判词要比数字更狠，而且**否定的是工作方式，不是工具**。

---

## 关键手法四：切档必须清定时器

```js
function play(mode) {
  timers.forEach(clearTimeout); timers = [];   // ← 学员会在动画播到一半时切档
  btnBad.className  = 'mode' + (mode === 'bad'  ? ' on-bad'  : '');
  btnGood.className = 'mode' + (mode === 'good' ? ' on-good' : '');
  ...
}
```

**这是所有「可打断的序列动画」的必备项**，不清就会两档叠在同一条时间线上。

---

## 选材要求

坏的那一档**不能是「AI 胡说」**，最好是**正确但没用的场面话**。

例：问「我们的差旅报销上限是多少」
- 坏档：「一般来说，企业差旅报销标准会根据职级和城市有所不同，建议您咨询公司的财务部门…」
- 好档：「住宿每晚不超过 500 元…〔来源：差旅费管理办法.pdf · 第 3 条〕」

**真实痛点常常就是「用正确的话说没用的事」，这个选材比「AI 编造」更准。**

---

## 进阶：好答案要教「怎么验收」

好的那一档里，**把可核对的部分做成视觉标记**（如一颗绿色的「来源」药丸）。

> 例：`〔来源：差旅费管理办法.pdf · 第 3 条〕`

它教的不只是「有对比更好」，而是**「什么样的回答才算可信」**——一个能迁移到所有输出的验收标准。

---

## 节拍

| | 时长 |
|---|---|
| 每条气泡入场 | 600ms |
| 坏档 9 条 | ~5.4s |
| 好档 5 条 | ~3.0s |
| 判词出现 | 最后一条之后 350ms |

---

## 陷阱

- **默认播好的那档** → 失去厌恶没了，学员只会点头。
- **两档步数一样** → 「差的几步」就没有呈现空间。
- **坏档用红字直接标「错」** → 应该让**步数**和**虚线**说话，而不是给结论。
- **切换档位不清定时器** → 两档动画打架。
