# 15 · 前后对照动画（自动演示，不要求读者找错）

**何时用**：内容有一组**前后结果**——改前失败、改后成功，且差别只在一处；读者需要**看懂为什么**，而不是自己把坏点找出来。
**心理机制**：对比 + 因果链。
**判据**：改前和改后**各有一个具体结果**；两版只差**一个决定性改动**；把这个改动讲清楚，比让读者猜更有效。

> 与 `07 A/B 对比` 的分界：**`07` 让读者在两条路里选（有交互、默认播坏的那档）；`15` 只播放，读者不选。**
> 与 `11 找错` 的分界：**`11` 要读者在一整块材料里主动定位坏点；`15` 直接把坏点和修复过程演示出来。**
> 什么时候用 `15` 而不是 `11`：**坏点太难找、或教学目标不是「审稿能力」而是「看懂机制」时，用 `15`。**

---

## 两种呈现：门口场景 vs 文档对照

### A. 门口场景版（推荐）

适合：关键差异是一个 **AI 行动前会检查的「门牌 / 开关 / 门槛」**——description、权限、关键词、参数阈值。

```
[任务] → [AI] → 看门牌（description）
                    ├─ 对不上 → 不进门 → 失败结果
                    └─ 对上了 → 进门读正文 → 成功结果
```

**视觉重点**：屋里四处都改好了（✓），但 AI 站在门外只看得到门牌；门牌没换，里面改得再全也进不去。门牌、门、屋内三个层次把「AI 只看 description」变成一眼能看懂的因果。

**示例（现成 Skill 改造，1.2-04）：**

> AI 走到 `Skill 文件夹` 门口，门牌写着「Anthropic 品牌」→ 和「双十一海报」对不上 → 不进门，产出大红底金字；
> 把门牌换成「小q 品牌 / 海报 / 通知」→ 对上了 → 门打开，读取 SKILL.md，产出浅灰底青柠绿。

### B. 文档对照版（兜底）

适合：内容没有天然的「门」隐喻，只有一份改前材料、一份改后材料。

```
[改前材料] → [判断面板：对不上] → [失败结果]
     ↓ 改一处
[改后材料] → [判断面板：对上了] → [成功结果]
```

结构：左文档、右判断面板、下方两张结果并排；改前压暗、改后点亮。状态机的写法与场景版一致，只是把「门牌」换成一整块文档。

```js
(function () {
  var svg = $('storySvg'), btn = $('fixPlay'), cap = $('fixCap');
  if (!svg || !btn || !cap) return;
  var ai = $('storyAi'), gaze = $('storyGaze'), door = $('storyDoor'), read = $('storyRead');
  var plate = $('storyPlate'), plateBad = $('storyPlateBad'), plateGood = $('storyPlateGood');
  var verdict = $('storyVerdict'), rule = $('fixRule');

  var timer = [];

  function clear() { timer.forEach(clearTimeout); timer = []; }
  function at(ms, fn) { timer.push(setTimeout(fn, R(ms))); }
  function paint(text) { cap.textContent = text; }
  /* SVG 上 .hidden 属性不生效，必须切 attribute */
  function show(el, on) { if (on) el.removeAttribute('hidden'); else el.setAttribute('hidden', ''); }
  /* SVG 的 className 只读，切 class 用 setAttribute */
  function setClass(el, cls) { el.setAttribute('class', cls); }

    clear();

    gaze.classList.remove('on');
    door.classList.remove('open');
    plate.classList.remove('good');

    show(plateGood, false);
    show(read, false);
    setClass(verdict, 'verdict bad');
    verdict.textContent = '✗ 对不上，不调用';

    goodFig.classList.remove('on');
    rule.hidden = true;
    paint('点「播放动画」，看 AI 为什么站在门口不进去。');
  }

    reset();
    plate.classList.add('good');
    show(plateBad, false);
    show(plateGood, true);
    ai.classList.add('walk');
    door.classList.add('open');
    show(read, true);
    setClass(verdict, 'verdict good');
    verdict.textContent = '✓ 对上了，进门读取';
    badFig.classList.remove('on');
    goodFig.classList.add('on');

    btn.textContent = '↻ 再看一遍';

      gaze.classList.add('on');

    });

      badFig.classList.add('on'); goodFig.classList.remove('on');
      paint('对不上，AI 就不进门——{失败结果}。');
    });

      ai.classList.remove('bad');
      ai.classList.add('walk');
      gaze.classList.remove('on');
      plate.classList.add('good');
      show(plateBad, false);
      show(plateGood, true);
      setClass(verdict, 'verdict good');
      verdict.textContent = '✓ 对上了，准备进门';
      paint('把门牌换成 {门牌 · 改后}，再跑同一句话。');
    });
    at(4600, function () {
      ai.classList.add('walk');
      door.classList.add('open');
      show(read, true);
      setClass(verdict, 'verdict good');
      verdict.textContent = '✓ 对上了，进门读取';
      badFig.classList.remove('on');
      goodFig.classList.add('on');

      paint('{成功结果}。');
```

## 三条关键手法

### ① 把「AI 看不到里面」画出来

屋内四处都打 ✓，AI 却站在门外，视线只连到门牌。**读者的注意力自然落到门牌上**——这就是「description 决定要不要调用」的视觉证据。不要一上来就把整份 SKILL.md 摊开；摊开以后，读者会以为 AI 也看得到。

### ② 只改一处，而且让这一处「可见地」改变

门牌从 `Anthropic 品牌` 换成 `小q 品牌 / 海报 / 通知`，红框变蓝框；同时 AI 的 X 眼回到正常、门打开、读取徽章出现、结果海报翻转。**一个改动，四个可见后果**，因果链就成立了。

### ③ 两个结果都保留

改前海报压暗、改后海报点亮；不要 `display:none` 把改前删掉。静态截图、减少动效、打印都能看到完整对照，读者也不用凭记忆回想改前长什么样。

### ④ 收尾必须抽象成一句规则

最后一句不要复述过程，要给可迁移的判断。例：

> 「门牌没换：屋里全换了，门口那块牌子还挂着上一个人的名字。改现成 skill，先换 description——它是 AI 决定要不要调用的唯一依据。」

## 节拍

| 动作 | 间隔 |
|---|---|
| AI 看向门牌 | 300ms |
| 亮出坏门牌 + X 眼 | +1000ms |
| 展示失败结果 | +1000ms |
| 换门牌 + AI 走向门口 | +1100ms |
| 门打开 + 读取徽章 + 成功结果 + 规则 | +1200ms |
| 收束 caption | +1200ms |

- 总时长 5–7 秒；超过 7 秒必须给「↻ 再看一遍」。
- `prefers-reduced-motion`：直接 `finalState()`，两个结果同时可见（改前压暗、改后点亮）。

## 陷阱

- **门向上滑** → 会盖住屋内标题和四行改动；**门向右滑**或做缩小/旋转，别遮住内容。
- **用 SVG 的 `.hidden` 属性** → 不生效；必须 `setAttribute('hidden','')` / `removeAttribute('hidden')`。
- **用 `.className` 切 SVG class** → `SVGElement.className` 只读，会抛错；用 `setAttribute('class', …)` 或 `classList`。
- **思考气泡不跟着 AI 走** → 把气泡放进 AI 组；AI 移动时把气泡淡出，否则会被房子裁掉。
- **视线标签不跟着消失** → 用 `.gaze.on + .gaze-label` 或同步切隐藏，别让「AI 只看得到门牌」压在移动后的 AI 身上。
- **门内徽章和黑色门洞同色** → 读取徽章用蓝底白字，别用低对比半透明。
- **前后差太多处** → 因果糊掉；只留一个决定性改动。
- **把改前结果删掉** → 读者失去对照；必须保留并压暗。
- **让读者先找错** → 那是 `11 找错`；`15` 的目标是「看懂」，不是「审稿」。
- **没有收尾规则** → 学员只记住这一次；最后一句必须能迁移。
