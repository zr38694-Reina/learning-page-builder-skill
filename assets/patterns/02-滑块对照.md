# 02 · 滑块 + 单变量对照

**何时用**：内容有**可调的参数**——对话轮数、模型规模、用量、时长、份数。
**心理机制**：失去厌恶 + 对照翻转。
**判据**：有一个自变量，改它会导致结果**从「好」翻转到「坏」**。只是数值变大变小，不足以支撑这个题型。

---

## 核心结构：单变量对照

问题、条件、语气**全部不变**，只改一个自变量：

```js
var CAP = 8;                              // 容量上限
var KEY_IDX = 1;                          // 关键项在第 1 位
var start = Math.max(1, r - CAP + 1);     // 窗口起点
var keyStillThere = (start === 1);        // ← 唯一的自变量带来的判定

if (keyStillThere) {
  elA.className = 'cw-a good';
  elA.textContent = '推荐一碗清汤牛肉面。你提到过对花生过敏，帮你避开了所有带花生的选项。';
  elWhy.textContent = '第 1 轮的纸条还在台面上，它答题的时候看得见那句话。';
} else {
  elA.className = 'cw-a bad';
  elA.textContent = '推荐我们的招牌花生酱拌面！酱香浓郁，拌开超香。';
  elWhy.textContent = '那张纸条已经被挤下去了。它没变笨，只是这次回答时根本看不见那句话。';
}
```

**答案从「体贴」翻转成「危险」——这比任何描述都有说服力。**

---

## 实现：FLIP + 增量渲染（高频控件必用）

滑块 `input` 是**高频连续事件**。**禁止清空重绘**（拖起来会整块闪烁）。分四步：

```js
function render() {
  var r = parseInt(range.value, 10);
  var start = Math.max(1, r - CAP + 1);

  // 0. 记下每个元素当前位置（FLIP 的起点）
  var deskRect = desk.getBoundingClientRect();
  var oldRects = {};
  Object.keys(notes).forEach(function (k) { oldRects[k] = notes[k].getBoundingClientRect(); });

  // 1. 移出窗口的：向前挤出的克隆成幽灵飞出，其余直接 remove
  Object.keys(notes).map(Number).forEach(function (n) {
    if (n >= start && n <= r) return;
    if (n < start) {
      var rc = oldRects[n];
      var ghost = notes[n].cloneNode(true);
      ghost.className = 'unit show unit-ghost';
      ghost.style.left = (rc.left - deskRect.left) + 'px';
      ghost.style.top  = (rc.top  - deskRect.top)  + 'px';
      ghost.style.width = rc.width + 'px';
      desk.appendChild(ghost);
      requestAnimationFrame(function () {
        requestAnimationFrame(function () { ghost.classList.add('gone'); });
      });
      setTimeout(function () { ghost.remove(); }, R(420));
    }
    notes[n].remove();
    delete notes[n];
  });

  // 2. 补新进窗口的（往回拖时按序插回正确位置）
  for (var n = start; n <= r; n++) {
    if (notes[n]) continue;
    var el = makeNote(n);
    var ref = null;
    Object.keys(notes).map(Number).sort(function (a, b) { return a - b; })
      .some(function (k) { if (k > n) { ref = notes[k]; return true; } });
    desk.insertBefore(el, ref);
    notes[n] = el;
    requestAnimationFrame(function (node) {
      return function () { node.classList.add('show'); };
    }(el));
  }

  // 3. 留下的做 FLIP 平滑补位
  Object.keys(notes).forEach(function (k) {
    var el = notes[k], old = oldRects[k];
    if (!old) return;
    var now = el.getBoundingClientRect();
    var dx = old.left - now.left, dy = old.top - now.top;
    if (!dx && !dy) return;
    el.style.transition = 'none';
    el.style.transform = 'translate(' + dx + 'px,' + dy + 'px)';
    requestAnimationFrame(function () { el.style.transition = ''; el.style.transform = ''; });
  });

  // 4. 被挤掉的项逐张累积到台下（只增不减）
  renderFallen(start);
  flipVerdict(start === 1);
}
```

> [!important] 为什么要 FLIP
> **动画的分层结构要复刻概念的分层结构。**
> 飞出去的（被挤掉）、新进来的（新的一轮）、留在台面上的（还在记忆里的）、掉在地上的（永久丢失）。
> 四个教学语义，四个动效层。这不是「加个动画让它好看」，是**用动效实现方式把概念结构表达出来**。

---

## 三条制造损失感的手法

1. **关键项全程被标记**：在窗口里是琥珀边框，掉下去后是琥珀删除线。它一直是「特殊的」，所以掉下去时学员会注意到。
2. **掉落不可撤销、只增不减**：台下累积删除线 chip，一直显示「已有 **7** 项被挤下台面，它答题时再也看不见这些」。
3. **掉落有物理过程**：`translateX(-90px) rotate(-8deg)` 飞出台面 `380ms`——**不是「消失」，是「被推下去」**。

---

## 节拍

| 动作 | 时长 |
|---|---|
| 拖动（即时） | 0 |
| 幽灵飞出 | 380–420ms |
| 新项入场 | 300ms |
| 判词切换 | 250ms |

**滑块区间要够长**（1–30 好过 1–10）：让学员有机会一路拖到底，看到累积的损失。

---

## 陷阱

- **用清空重绘** → 拖动时闪烁，学员以为页面坏了。
- **掉落项不累积** → 拖回去就全复原，损失感为零。
- **没有「回到起点」的提示** → 学员拖到 30 后不知道该拖回去。给一句文案或一个重置按钮。
- 滑块缺 `aria-label` / `aria-valuetext`（这是本系列实测最常见的无障碍缺口）。
