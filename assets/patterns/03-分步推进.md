# 03 · 分步推进 + 终态对比

**何时用**：内容有**可拆的流程**——三步、四层、五个环节。
**心理机制**：对比 + 可验证性。
**判据**：步骤之间有明确的**先后因果**，且最后一步的产出**可被核对**。

---

## 结构

```
[① 步骤一] [② 步骤二] [③ 步骤三]        ← 可点跳步
────────────────────────────────
  当前步骤的内容（逐条入场）
────────────────────────────────
        [ 下一步 / 从头再看 ]
```

两层内容：**步骤导航**（可点）与**步骤内容**（里面可能还有不可点的演示元素）。
**可点的和不可点的，在视觉上要分得开。**

---

## 实现

```js
var dots = document.querySelectorAll('.step-dot');
var scenes = [ $('scene0'), $('scene1'), $('scene2') ];
var nextBtn = $('next');
var cur = 0, timers = [];

function clearTimers() { timers.forEach(clearTimeout); timers = []; }

function show(idx) {
  clearTimers();
  cur = idx;
  dots.forEach(function (d, i) {
    d.classList.toggle('on', i === idx);
    d.setAttribute('aria-selected', i === idx ? 'true' : 'false');
  });
  scenes.forEach(function (s, i) { s.classList.toggle('on', i === idx); });
  nextBtn.textContent = (idx === scenes.length - 1) ? '从头再看' : '下一步';

  // 重置本幕的入场动画
  var items = scenes[idx].querySelectorAll('.step-item, .chip');
  items.forEach(function (el) { el.classList.remove('show'); });

  // 逐条入场；遇到成组的 chip 逐张弹出
  var delay = 0;
  scenes[idx].querySelectorAll('.step-item, .chip-row').forEach(function (el) {
    if (el.classList.contains('step-item')) {
      delay += R(450);
      (function (node, d) {
        timers.push(setTimeout(function () { node.classList.add('show'); }, d));
      })(el, delay);
    } else {
      el.querySelectorAll('.chip').forEach(function (chip, ci) {
        (function (node, d) {
          timers.push(setTimeout(function () { node.classList.add('show'); }, d));
        })(chip, delay + 200 + ci * 120);
      });
      delay += 200 + el.querySelectorAll('.chip').length * 120;
    }
  });
}

dots.forEach(function (d, i) { d.addEventListener('click', function () { show(i); }); });
nextBtn.addEventListener('click', function () { show((cur + 1) % scenes.length); });
show(0);
```

---

## 三条关键手法

### ① 在流程里埋一个「暂停点」

流程演示最容易出外行误解的地方，放一条**独立的**提示卡，而不是写进解释段。

> 例：讲「检索 → 生成」时，在第 ② 步末尾单独放一条：
> **📌 注意：这一步只是「翻书」，AI 还没开口。**

因为读者刚看完「命中了两张卡片」的动画，最自然的联想就是「AI 已经知道了」。
**读者的误解是紧接着动画产生的，就要紧接着动画打断它。**

### ② 用颜色把抽象动作翻译成不用读的结论

「按**意思相近**去找」这个抽象描述 → 让命中的那几张卡片**变绿**（`.hit`）。
一处绿色 = 一句不用读的结论。

### ③ 让「缺失项」全程挂在场上，最后才点亮

需要制造张力时：把那条「还缺的一句」从第一步就摆在屏幕上（暗的），**只有走到最后一步才高亮发光**。
视觉上的「一直缺一块」比文字说明更能制造张力。

---

## 节拍

| | 时长 |
|---|---|
| 每条入场 | 450ms |
| 成组 chip 逐张 | 120ms / 张 |
| 幕间切换 | 即时（淡入 300ms）|

**总时长控制在每幕 3 秒内。** 三幕加起来不超过 10 秒。

---

## 陷阱

- **只能按「下一步」线性走** → 想回看的学员会一路点到「从头再看」。**允许点导航直接跳步**。
- **切幕不清定时器** → 快速连点「下一步」时，上一幕的入场动画会渗到下一幕。
- **步骤导航用 `<div onclick>`** → 键盘用户完全无法操作。用 `<button>`，并加 `role="tablist"` + `aria-selected` + `aria-controls`（或整组 `aria-live`）。
