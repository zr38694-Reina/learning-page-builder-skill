# 16 · 对话气泡流（逐条冒出 + 窗口渐满）

> donor 机制取自 `Skill微PBL1.1-01`（STEPS + rAF 累计时间轴）；成页 donor 待补。选型语境见 `references/02-动画流程选型.md`「一·补」。

**何时用**：内容是**一段多轮对话**或「上下文越堆越多」的过程——多轮记忆、上下文窗口、为什么聊久了会「忘」、为什么每轮都要重新交代。
**心理机制**：见证 + 负担感（窗口一点点被填满，读者眼看空间耗尽）。
**判据**：至少 3 条消息；消息有先后依赖；最后一条消息出现时，前面几条**仍然占着位置**（这正是要讲的重点）。逐条独立、互不依赖的清单用 `06`。

> 与 `14 流转流程图` 的分界：`14` 讲系统流向（节点传递），`16` 讲**堆积**（消息只增不减）。
> 与 `06 播放动画` 的分界：`06` 是节点行 + 字幕面板，`16` 的主体就是气泡本身，不另设节点行。

---

## 结构

```
┌────────────────────────────┐
│ [用户] 帮我写周报            │  ← 逐条冒出，只增不减
│        [AI] 好的，先取数据…  │
│ [用户] 第二轮，还要填考勤…    │
│ ╌╌╌╌ 上下文窗口 ╌╌╌╌╌╌╌╌╌   │  ← 窗口线，气泡逼近它 = 空间将尽
└────────────────────────────┘
字幕条：这一步堆进了什么、意味着什么
```

**必须有：**

- 用户 / AI 两种气泡，**左右交错**（用户左、AI 右或相反，全页统一）；
- 一条**窗口线**（虚线，底部）：气泡总数逼近它时字幕必须点破「快满了 / 早期的被挤掉了」；
- 旧气泡**永不消失**——消失就讲不了「记不住」；需要讲「截断」时，让最早的气泡降透明度（`.old`，opacity .35），不是移除；
- 每条气泡 ≤1 行正文（≤14 字），完整语义放字幕条。

## 实现

### HTML 骨架

```html
<div class="chat-stage" id="chatStage">
  <div class="chat-flow" id="chatFlow">
    <div class="bubble user" data-ci>帮我写周报</div>
    <div class="bubble ai" data-ci>好的，先取上周数据…</div>
    <div class="bubble user" data-ci>第二轮，还要填考勤</div>
    <!-- 每条一个 .bubble，data-ci 不需要编号 -->
  </div>
  <div class="chat-win" id="chatWin"><span>上下文窗口</span></div>
  <p class="chat-cap" id="chatCap" role="status" aria-live="polite">点「播放」，看对话怎么一点点堆满窗口。</p>
</div>
```

### JS（rAF 时间轴，donor 1.1-01 同款）

```js
var flow = $('chatFlow'), cap = $('chatCap');
var bubbles = [].slice.call(flow.querySelectorAll('.bubble'));
var STEPS = bubbles.map(function (b, i) {
  return { t: 400 + i * 1100, el: b,
           text: ['第 1 句字幕…','第 2 句字幕…'][i] || '…' };  /* 每条一句 */
});
var END = 400 + bubbles.length * 1100 + 800;
/* state/idx/base/startedAt/frame/finalState 全部照抄 1.1-01：
   frame 里 while(elapsed>=STEPS[idx].t){el.classList.add('in');paint(text)}；
   finalState 全部 .in + 收束字幕（例：「三轮下来，最早的交代还在占地方——窗口就这么被堆满的。」）；
   REDUCED 直接 finalState；↻ 再看一遍 = remove('in') 重播。 */
```

需要讲「截断」：终态前加一步，把最早 1–2 条 `classList.add('old')`，字幕「最早的这轮已经滑出窗口，AI 看不见了」。

## 节拍

| 动作 | 间隔 |
|---|---|
| 每条气泡冒出 | 400ms 起步，每条 +1100ms |
| 旧气泡降透明（可选截断步） | 最后一条后 +1000ms |
| 收束字幕 | 最后一步 +300ms |

- 总时长 4–7 秒；气泡超过 6 条就砍对话（真实感靠台词质量，不靠条数）。

## 陷阱

- **气泡带长正文** → 气泡只留 ≤14 字一行；解释全部进字幕条，否则窗口被气泡撑爆。
- **旧气泡消失** → 消失 = 把「记不住」讲成了「换话题」；只能降透明度。
- **没有窗口线** → 堆积失去参照物，负担感出不来；窗口线是这个形态的灵魂。
- **左右不分** → 用户/AI 必须交错且有视觉区分（底色 + 圆角方向），否则读不出「对话」。
- **台词写成名词解释** → 气泡是人说话，不是概念定义；教学话全放字幕。
