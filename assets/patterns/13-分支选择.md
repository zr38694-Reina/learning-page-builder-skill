# 13 · 分支选择（走一条路，代价延迟显形）

**何时用**：内容有**多步决策链**——每一步的选择改变后续，且错误不会立刻报错。
**心理机制**：因果体验（「我以为没事」→ 三步之后出事）。
**判据**：错误选择**不立刻报错**，而是**几步之后才显形**。这是它与一切对比题型的根本区别。

> 与「A/B 对比」（`07`）的分界：**`07` 是一次性两档（当场比出好坏），`13` 是走完一条路（代价延迟显形）。**
> 要「立刻比出好坏」用 `07`；要「让人体会因果链」用 `13`。
> `13` 的实现成本明显高于 `07`——**只在「延迟后果」本身就是教学点时才用**。

---

## 结构：一棵浅树

```
① 你打算怎么让 AI 帮你写周报？
   ├─ 让它直接写         → ②
   └─ 先喂它这周的记录   → ②'
② （一步之后 —— 一切正常）
③ （两步之后 —— 这里才爆）
──────────────────────────────
[ 重走一遍 ]   [ 看另一条路 ]
```

**树要浅**：3–4 个岔口、每个岔口 2–3 个选项，总节点控制在 12 个以内。
再深学员会迷路，你也写不完。

---

## 实现要点

```js
var TREE = {
  start: {
    q: '你打算怎么让 AI 帮你写周报？',
    opts: [
      { text: '让它直接写',       next: 'vague' },
      { text: '先喂它这周的记录', next: 'fed'   }
    ]
  },
  vague: {
    q: '它写出来了，读起来还行。要发吗？',
    opts: [
      { text: '直接发',     next: 'blowup'  },   // ← 雷在这里爆
      { text: '再自己改改', next: 'rescued' }
    ]
  },
  blowup: {
    // 延迟显形：这里才揭示前两步埋下的因
    verdict: '邮件发出去两小时后，老板回复：「上周不是说了这个项目延期吗？」'
           + '——它不知道这件事，因为你从没告诉过它。'
  }
};
```

**每个终点都要能回指前面埋的因**：

> 「它不知道这件事」——**因为你第 ① 步没有喂它。**

**这一句是整棵树的落点。** 没有它，学员只是玩了个游戏。

---

## 三条手法

### ① 雷不埋在选择里，埋在「看起来最省事的那一步」

错误选项要写成**最诱人的那个**。学员选了它，要觉得「这很合理啊」——
否则学员会一路选对，然后说「这还用教」。

### ② 爆点之前，先给一段「一切正常」

延迟显形的关键是**中间那几步不能有异样**。
第二步可以照常推进、甚至给正面反馈（「它写出来了，读起来还行」）——
**越顺，第三步的爆越疼。**

### ③ 收尾给「回到第几步可以救」

```js
// 不要只说「你错了」，要说「你从哪一步开始错的」
var PIVOT = { blowup: '第 ① 步——你没告诉它项目延期了。' };
```

> 你这次在第 **①** 步走岔了。**如果重来，只要在那儿加一句「这周项目延期了」，后面全都会不一样。**

**给「可回退的岔口」，不给「你太粗心」。**
判词否定的是这一步的选法，不是人（同 `07`）。

---

## 节拍

| 动作 | 时长 |
|---|---|
| 每步节点切换 | 淡入 300ms |
| **爆点（代价帧）** | **明显更长：800–1200ms，且留白** |
| 回溯提示 | 400ms |

**爆点这一帧要停最久**（同 `02-互动策略选型.md` §三「代价帧放慢」）。
可以在这一帧前加一个短暂空档（`~400ms`），让学员先自己意识到不对。

---

## 陷阱

- **选错立刻报错** → 退化成 A/B 对比，用 `07` 就行。**`13` 的全部价值在延迟。**
- **正确路径太明显** → 学员一路选对，什么都没体会到。**错误选项要是最省事、最诱人的那个。**
- **树太深（> 5 个岔口）** → 学员迷路、你也写不完。**3–4 个岔口。**
- **爆点之后不给回溯** → 学员只知道错了，不知道该回哪一步。**必须给「可回退的岔口」。**
- **爆点匀速播** → 代价帧失去重量（同 `05` 陷阱）。
- **拿它讲没有决策链的内容**（只有一次选择）→ 那是 `07`。**有 3 步以上的因果才用 `13`。**
