# 17 · 时间条退避（间隔递增可视化）

> 选型语境见 `references/02-动画流程选型.md`「一·补」；点亮机制与 `14 流转流程图` 同源（`.on` 累加）。首用成页：`智谱1.2.4-API报错到底该改哪一层-学习页.html`（拍 4，2026-11-04 打入）。

**何时用**：内容里有**递增的等待 / 间隔 / 累积量**——指数退避、重试间隔、成本累计、Token 消耗。一句话字幕（「间隔越拉越长」）讲不出体感，条形能。
**心理机制**：体感夸张（第 3 条是第 1 条的 4 倍长，眼睛先于数字感受到「等不起」）。
**判据**：至少 3 个间隔；倍率 ≥2（1s/2s/4s）；间隔之间有动作（重试一次、再失败一次）。没有递增关系的量不硬套。

> 与 `14` 的分界：`14` 讲链路流向，`17` 讲**一个量的递增**；17 常作为 14 / 线性五拍某一拍**内部**的示意区（`.anim-vis` 位），不独立成装置。

---

## 结构

```
▍1s        ← 第 1 次失败后等 1 秒
████ 2s      ← 第 2 次失败后等 2 秒
████████ 4s  ← 第 3 次：条长跟着倍率走
字幕：间隔越拉越长——退避是给对方喘息，也是给自己止损。
```

**必须有：**

- 条长严格按倍率（宽度 = 基准 × 倍率，最大条 ≤ 容器宽的 70%，留标签位）；
- 每条右端一个数值标签（1s / 2s / 4s）；
- 条与条之间可插「动作词」（重试 ✗），但**不占独立行**——贴在下一条的行首；
- 收束字幕给「为什么这么设计」，不复述数字。

---

## 实现（两种落位）

### A. 独立 SVG（全图流程图内部的一组节点）

```svg
<g class="sk-bars" data-step="3">
  <rect class="sk-bar" x="120" y="180" width="56"  height="14"/>
  <text class="sk-bar-t" x="184" y="192">1s</text>
  <rect class="sk-bar" x="120" y="204" width="112" height="14"/>
  <text class="sk-bar-t" x="240" y="216">2s</text>
  <rect class="sk-bar" x="120" y="228" width="224" height="14"/>
  <text class="sk-bar-t" x="352" y="240">4s</text>
</g>
```

```css
.sk-bar{fill:var(--f-tint-teal,#eaf8f4);stroke:var(--f-teal,#2fae95);stroke-width:1.4;
  transform:scaleX(0);transform-origin:120px 0;transition:transform .5s ease}
.sk-node.on .sk-bar,.sk-bar.on{transform:scaleX(1)}
```

播放：按 STEPS 逐条 `classList.add('on')`（累加，不撤销）；条从左往右**长出来**（scaleX），比淡入更有「拉长」感。条宽超过 300px 时改用 `transform-origin:left` + 容器 `overflow-x:auto`，窄屏语义不变。

### B. 嵌进切换式五拍的示意区（`.anim-vis` 位）

```html
<div class="anim-vis bars">
  <div class="bar-row"><i style="--w:25%"></i><span>1s</span></div>
  <div class="bar-row"><i style="--w:50%"></i><span>2s</span></div>
  <div class="bar-row"><i style="--w:100%"></i><span>4s</span></div>
</div>
```

```css
.bar-row{display:flex;align-items:center;gap:8px;height:20px}
.bar-row i{display:block;height:14px;width:var(--w);background:var(--accent);
  transform:scaleX(0);transform-origin:left;transition:transform .45s ease}
.anim-step.show .bar-row i{transform:scaleX(1)}
.anim-step.show .bar-row:nth-child(2) i{transition-delay:.25s}
.anim-step.show .bar-row:nth-child(3) i{transition-delay:.5s}
```

拍亮起时三条依次长出来——**不需要 JS**，纯 CSS transition-delay，适合切换式五拍不想加 JS 的场合。

---

## 节拍

| 动作 | 间隔 |
|---|---|
| 第 1 条长出 | 300ms |
| 第 N 条长出 | 上一条 +700ms（条多时 550ms） |
| 数值标签 | 与条同时（就在条旁，不用单独步） |
| 收束字幕 | 最后一条 +400ms |

## 陷阱

- **条长和数字对不上** → 读者会拿尺子量；宽度必须严格按倍率，容器不够就整体缩，不破比例。
- **超过 4 条** → 观感疲劳且倍率爆炸（1/2/4/8/16 要 16 格宽）；4 条后直接收束，字幕带过「再往后是 8s、16s」。
- **条是主角，字幕抢戏** → 字幕只收一句「为什么」；把退避原理写成三行就回知识卡片去。
- **递增没来由** → 出现 3 条互不相干的量各画一条，是图表不是动画；时间条必须挂在「同一件事的反复」上。
