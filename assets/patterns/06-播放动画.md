# 06 · 播放：让人「看见」一个过程

**何时用**：内容只能**看见**，是一次经历而不是一道题——「它实际跑起来什么样」「这一步步是怎么做的」。
**心理机制**：见证。
**判据**：读者**从没见过**这个过程（如果他见过，就不需要动画了，改成前后对照即可）。

> 对照手法：**对比演示的两侧不需要同等的信息量，只需要各自完成各自的认知任务。**
> 让你「认出来」的那一侧（静态三步就够） vs 让你「没见过」的那一侧（要做成能播的、有节奏的、有细节的）。

---

## 实现

```js
var steps = [].slice.call($('steps').querySelectorAll('.step'));
var btn = $('play');
var progress = $('progress');   // 「第 N / M 拍」
var timers = [];

/* 切换式（SKILL.md 红线 16）：同屏永远只有一拍，五拍不叠在一屏。
   CSS 上各拍 grid-area:1/1 叠同一网格单元、.show 独占；
   退场瞬时、入场淡入；容器高度取最高一拍，切拍不跳版。 */
function showStep(i) {
  steps.forEach(function (s, k) { s.classList.toggle('show', k === i); });
  progress.textContent = '第 ' + (i + 1) + ' / ' + steps.length + ' 拍';
}

function play() {
  clearTimers();
  var i = 0;
  showStep(0);                                   // 第一拍立刻出来，不空等
  (function next() {
    /* 停留时间挂在「当前拍」身上：代价帧把它的 data-hold 给大，就是放慢 */
    var hold = R(steps[i].dataset.hold ? +steps[i].dataset.hold : 550);
    i++;
    if (i >= steps.length) {
      timers.push(setTimeout(function () {       // 最后一拍停够再收尾
        btn.textContent = '↻ 再看一遍';
        $('verdict').classList.add('show');
      }, hold));
      return;
    }
    timers.push(setTimeout(function () { showStep(i); next(); }, hold));
  })();
}

function clearTimers() { timers.forEach(clearTimeout); timers = []; }
btn.addEventListener('click', play);
```

**按钮会自己变成「↻ 再看一遍」**——3 秒的动画一遍看不清，必须给回看的门。

## 三条手法

### ① 在「全自动」的演示里插一个人工确认点

如果演示的是一个自动化流程，**留一个「停下来问你」的点**，并用特殊样式标出来：

> 🙋 **拿不准就问**：「第 7 张照片有点糊，金额是 380 还是 880？」——你回一句，它继续

再加上收尾的一句「你全程只回答了一个问题 ☕」——**把「人工介入」从成本重新叙述成参与感**。

### ② 让「缺失项」在最后才点亮

见 `03-分步推进.md` 手法 ③。

### ③ 把体验变成两个数字

收尾用对比数字代替形容词：

```
跑了 4 趟 · 问了你 3 次      1 趟搞定 · 0 次打扰
```

**判词写得比数字更狠更好**：「每做一步就回来确认一次——**你比自己动手还累**。」
它否定的不是工具，是**你选择的工作方式**。

## 自动播放：进入视野才播，且只播一次

```js
var played = false;
function onView(el, cb, ratio) {
  if (!window.IntersectionObserver) { cb(); return; }
  var io = new IntersectionObserver(function (entries) {
    entries.forEach(function (e) {
      if (e.isIntersecting) { io.unobserve(el); cb(); }
    });
  }, { threshold: ratio || 0.35 });
  io.observe(el);
}
onView($('demo'), function () { if (!played) { played = true; play(); } });
```

**用户滚到该处才播**，不是加载即播（加载即播时，学员滚到时动画早就播完了）。

## 节拍

| 片段 | 时长 |
|---|---|
| 开场 | 900ms |
| 普通步骤 | 550ms |
| **代价 / 浪费步骤** | **900ms** |
| 收尾 | 定格 300ms 后显示判词 |

---

## 陷阱

- **只给一次播放** → 学员想再看必须刷新。
- **「加载即播」** → 学员滚到时已经播完。
- **播放中不给打断** → 学员切档时，两轮的步骤叠在同一条时间线上（**必须 `clearTimeout`**）。
- **没有 `prefers-reduced-motion` 降级** → 长序列动画对动效敏感用户是负担。
