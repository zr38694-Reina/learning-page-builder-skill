# 11 · 找错（在一整块成品里定位那处坏点）

**何时用**：有一份**看似合理、实则带伤**的成品——回答、方案、笔记、代码、周报。
**心理机制**：专家视角代入 + 主动搜索（比被动读记得牢得多）。
**判据**：缺陷是**可定位的一处**，且**不定位就看不出来**（通读一遍不会自己跳出来）。

> 与「盲判」（`04`）的分界：**`04` 判的是「逐条给好的断言」（离散、给了清单），`11` 找的是「一整块连续材料里的那一处」（连续、不给清单）。**
> `04` 教「这句可疑」，`11` 教「**整篇里哪句坏了**」。
> 反过来，材料里的问题**多于 3 处、或彼此独立**时，用 `04` 更清楚。

---

## 数据形状

核心是**三个条件同时成立**：

```js
var DOC = {
  // ① 通体合理 —— 90% 的句子都站得住
  body: [
    '住宿费按职级分三档，总监级每晚不超过 800 元。',
    '市内交通凭票实报，单次不超过 100 元。',
    '餐补每人每天 120 元，出差期间按实际天数计。',
    '跨月出差可在次月 10 日前补交报销单。',
    '海外出差一律按当日汇率折算，汇率以报销当日为准。'   // ← 坏点：是「出差当日」，不是「报销当日」
  ],
  // ② 坏点可定位 —— 能指到具体某一句
  badIndex: 4,
  // ③ 坏点「看起来最像对的」
  why: '其余四条都是宽严得当的规定，只有这一条把两个「当日」接错了。'
};
```

**坏点最好恰恰是最像「精确＝可靠」的那一处**——
`04` 是在假里埋一真，`11` 是在真里埋一假，方向相反，逻辑同源。

---

## 实现要点

```js
doc.addEventListener('click', function (e) {
  var line = e.target.closest('.line');
  if (!line) return;
  var idx = +line.dataset.i;
  if (idx === DOC.badIndex) {
    line.classList.add('found');
    paint('找到了。' + DOC.why);
    if (!found) { found = true; paintHard(); }   // 首次命中才揭示「为什么它难找」
  } else {
    line.classList.add('miss');
    paint('这句没问题——它和别的规定不冲突。再找找。');
  }
});
```

**点错不给惩罚、也不消耗次数。**
目标是**让学员把每一句都读一遍**——点错一次就多读一句，这正是我们要的。

---

## 三条手法

### ① 坏点必须是「内部矛盾」，不是「明显离谱」

不要写「住宿费每晚不超过 99999 元」这种一眼假的。
要写**和上下文冲突、但单看很合理**的一句——
学员必须**把整篇当一个系统读**才能发现，**这才是审稿的真实动作**。

### ② 找错之后，给「这类错误的一般形态」

命中只是第一步。收尾要把它**抽象成一条可迁移的规则**：

> 这类错误叫**「细节接反」**——不是编造的，是把**两个都对的东西接错了**。
> 你在真实场景里核对时，**优先查「日期、主体、条款号」这三类**：
> 它们最容易接错，也最难被一眼看穿。

**没有这一步，学员记住的只是这一篇文档。**

### ③ 给一次「再找找」的机会，但只暗示位置

学员点了 2–3 句都没命中时，给一句**只缩范围、不报位置**的提示：

> 💡 问题在**后半段**，而且**和日期有关**。

---

## 节拍

| 动作 | 时长 |
|---|---|
| 点错 → 判词 | 220ms |
| 命中 → 高亮 | 300ms |
| 规则抽象（收尾） | 500ms |

- **不做自动播放**（同 `08`–`10`）。

---

## 陷阱

- **坏点一眼假** → 退化成送分题。**必须「单看合理、连读才发现」。**
- **点错就扣分 / 限次数** → 学员不敢点，就不读了。**点错不惩罚。**
- **命中即结束、不抽象规则** → 学员只记住这一篇。**收尾必须给「一般形态」。**
- **坏点多于 3 处** → 学员不知道要找几个，注意力散掉。**一处最锋利；要多处就用 `04`。**
- **拿它去审没有客观坏点的材料**（如「这段文案写得好不好」）→ 主观题。**有唯一坏点才用 `11`。**
