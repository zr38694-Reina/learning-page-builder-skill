# 08 · 归类分堆（拖入两堆 / 多堆）

**何时用**：内容有**可分类的条目**——每条都能归入某个类别，且有客观归属。
**心理机制**：分类行动暴露「我原来分不清」。
**判据**：条目之间存在**类别边界**，且读者常把其中两类混为一谈。

> 与「盲判」（`04`）的分界：**判真假 → 盲判；判归属 → 归类。**
> `04` 给的是「这一条断言可不可信」（单一断言，有对错）；
> `08` 给的是「这一条属于哪一类」（条目 × 类别体系，类别本身都成立）。
> 学员分不清「真假」用 `04`，分不清「归属」用 `08`。

---

## 数据形状

核心是**一组精心设计的「边界条目」**——不是随便凑的例子，是专挑两类之间最容易读错的那些：

```js
var CARDS = [
  { id: 'a', text: '把这份会议录音转成要点',       kind: 'ai'   },
  { id: 'b', text: '定这次改版的最终视觉方向',     kind: 'self' },
  { id: 'c', text: '把这段中文润色成英文',         kind: 'ai'   },
  { id: 'd', text: '判断要不要砍掉这个功能',       kind: 'self' },
  { id: 'e', text: '给这 30 条用户反馈做情感分类', kind: 'ai'   },
  { id: 'f', text: '决定这次要不要道歉',           kind: 'self' }
];
```

**组内必须有 3–5 张「一眼看不出来」的边界卡**（像 `d`「砍不砍功能」、`f`「要不要道歉」）。
全是大白话的送分卡，装置等于白做。

| 卡片类型 | 学员自己看出来的 |
|---|---|
| 「可外包的加工」（转写 / 润色 / 分类） | 「AI 能接的是**加工程**」 |
| 「要担责的判断」（定方向 / 砍功能 / 道歉） | 「我要留的是**判断与后果**」 |
| 边界卡（看着像加工，其实含判断） | 「我以为能交出去，其实不能」 |

**结论不要写在卡片上，写在正文里命名它。**

---

## 实现要点

三堆比两堆更耐玩（`ai` / `self` / `都要问我`），但**两堆的判词最锋利**。先用两堆。

```js
function drop(cardId, pile) {
  var card = CARDS.find(function (c) { return c.id === cardId; });
  var right = (card.kind === pile);
  card.el.className = 'card ' + pile + (right ? ' ok' : ' bad');
  judged[cardId] = right;
  paintTally();
}

// 每一张拖完立刻给判词：结论 → 为什么 → 一句延伸判断（句式与 04 统一）
function verdict(card) {
  return card.kind === 'ai'
    ? '这是可以交出去的加工——它不需要你承担后果。'
    : '这一步要你签字。交出去，等于把后果也交出去。';
}
```

**判词格式与 `04` 统一**：先说结论、再说为什么、最后给一条延伸判断。
句式统一成「这是 **X** 的……」，学员读到的是一段知识，不是一句判词。

---

## 三条必须遵守

1. **每张卡拖完立刻给判词，不要等全部拖完。**
   全部拖完再揭晓 = 学员在盲拖，中途那句「我分不清」没有被抓住——那正是本页要教的东西。

2. **不设「全部正确才有分」的门。**
   记分只在一处有效：收尾给**误分对照表**（哪两张卡被错得最多）。
   需要完成感时才上进度条，见 `02-互动策略选型.md` §二「不记分」。

3. **错分要留在落点上（红框），不要弹回原处。**
   弹回去 = 学员不知道自己错在哪；留在原地标红 = 学员看见「原来我把它算成加工了」。

---

## 节拍

| 动作 | 时长 |
|---|---|
| 拖动 | 即时 |
| 落位判词 | 250ms 淡入 |
| 收尾误分对照表 | 全部完成后 400ms |

- **不做自动播放**——归类是**主动动作**，自动播会把它变回看动画。

---

## 陷阱

- **卡片只有送分题** → 学员 30 秒拖完，什么都没发现。**边界卡才是主角。**
- **判词写成「对 / 错」** → 换成「这一类会 / 不会……」，语气从判词变成信息（同 `04`）。
- **三堆以上却不给类别定义** → 学员不知道边界在哪。**堆数越多，越要在每堆下标一句定义。**
- **把结论写进卡片文案**（如「润色英文（AI 可做）」）→ 失去发现感（同 `01` 陷阱）。
